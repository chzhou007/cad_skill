## Scope qualification after native comparison

`qualify_plan_DN_review_scope.qualify` consumes already source-checked local DN
results and the exact current graph. For a conflict group it checks all label
lineage edges, system isolation, source transfer incidence, endpoint source-T
provider gaps and annotation barriers. A gap elsewhere on a floor does not
prevent reviewing a separately proved conflict. A gap anywhere on the actual
evidence path does prevent it. This function is not CAD replay or topology
approval. Bind the original source/native result receipts when publishing.

Keep unchanged question fingerprints, original answers and browser drafts.
Publish large native CAD context with marked locations and a local source/graph
Pair. A newly enabled local question never accepts the whole drawing.

## Effective attribute inheritance

Source storage and effective UI/CSV behavior need separate regression checks.
Keep an independently checked prior whole-edge DN on a one-to-one same-floor
main if the current known plan DN agrees exactly but the new scope has unknown
metric extent. Record that the prior whole-edge evidence supplied it; do not
fill the current partial source scope. Current conflicts, unknown DN, differing
values, grouped paths and equipment drops do not qualify. Do not derive any
new pipe length from this retention. Compare all prior numeric CSV values in
the real whole drawing, not just counts or stored JSON.

After a proved equipment-caption permutation, normalize display inventory names
only through the exact original/current component CSV, same edge ownership and
complete name-count conservation. Run this cheap check before native ancestry.
Canonical graph bytes and historical source receipts stay immutable.

# Calibrated logical equipment/interface ownership

Use when retained native equipment and complete out-of-plane interface symbols are disconnected, and explicit user-confirmed examples provide an independently reproducible drawing convention. A nearby equipment rectangle alone does not prove ownership.

## Evidence and applicability

`calibrated_equipment_interface_ownership.py` pins target source/graph/component CSV, control source/graph and policy. Replay control `confirmedEquipmentPairReconstruction` and target `sourceEquipmentIdentityResolution`. Read Chinese strictly before interpreting geometry.

Each interface requires the complete typed CIRCLE plus four native branch-layer LINE glyph, a matching terminal center and exactly one same-system native pipe endpoint contact; competing interior contacts fail. Its edge must reference that pipe and reach the terminal. Preserve source XYZ/layer separately.

Learn pair spacing and bounded normal gap from confirmed examples with unique native body projections. Require the configured minimum controls and both orthogonal approach axes. Record unsupported confirmed patterns separately; a unique assignment contradicting its confirmed owner fails calibration. The gap margin is explicit policy, not a global snap tolerance.

Target services must share a floor and parallel pipe approaches in the same direction. Both terminals must project inside one body's tangent interval and outside the same normal face within the learned bound. Compare all retained native bodies with unique exact captions. Do not choose the nearest body, extrapolate unlearned spacing, resolve competing claims greedily or overwrite ownership. Tests cover rotated/mirrored bodies; unsupported source transforms remain pending.

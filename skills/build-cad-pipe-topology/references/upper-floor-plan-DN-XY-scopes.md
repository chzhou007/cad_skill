# Upper-floor plan attributes within mixed axis edges

After `match_named_riser_floor_segments.py` has independently verified named
interfaces, run `named_upper_floor_plan_attributes.py`. Replay the mapping,
current native through/branch roles, plan DN catalog and millimetre evidence.
The output is source evidence, separate from composition or viewer publication.

Build the DN domain from the two existing main bridges and their actual off
branches at both network and equipment Ts. An explicit branch DN overrides
that branch only; it cannot backflow into the through main. Qualify a riser
name/DN separately using its native underline, leader and exact target. Nearby
names, same DN or a shaft label alone cannot consume competing annotations.
Equipment branches required by this domain are context only when they already
have published attributes; they are not duplicate writers.

`touching_plan_path_coverage.py` adapts the inherited native coverage reader
only for ordered, exactly touching chunks on one existing edge. Reuse
`native_touching_plan_path_chunks.py` on a private projection and map every
coverage/metric segment back to its original path and segment indices. A real
gap still uses the inherited reviewed crossing/omission rules. Do not snap a
gap, join other edges or count a circle radius as pipe.

Transfer source DN and measured XY only within the mapped axis scopes. An
upper approach is the horizontal suffix of a mixed edge; its cross-floor
vertical segment retains SH16 11 evidence. Floor plans 08–10 do not determine
vertical length. Parenthesized DN labels remain uninterpreted unless separately
proved. Explicit SH16 11 dimensions/elevations must establish any vertical
physical length; drawn segment length is insufficient.

Use `pipeline.py validate-upper-floor-plan-attributes --attribute-run ...` for
independent source replay. Success returns pending/exit 2: segment-aware
composition, preservation of prior attributes and components, source comparison,
viewer checks and human acceptance still remain. No scalar DN for a mixed
edge or installed whole-edge length is selected by this scope stage.

Run native upper-floor DN/XY replay, `test_named_upper_floor_plan_attributes.py`,
`test_touching_plan_path_coverage.py`, `test_upper_floor_plan_attribute_gate.py`,
and inherited DN/T, native metric, wave, crossing, naming and segment-map tests.
SH16 10 E0025/E0011 are DN300 RIF approaches while E0026/E0012 are DN250 main
bridges. These four records do not establish other floors or all pipe lengths.

# 11图主管经真实三通继承到未标注竖段

剩余竖段没有同边种子时，先检查是否只是从省略接口接到已标注主管的管段。`reconstruct-axis-main-T-DN` 复用原模型空间标注归属、原生三射线、连续主管、两臂弯头和标注屏障读取器；`validate-axis-main-T-DN --native-run NEW` 独立重读原CAD。

1. 三通必须由当前图和原CAD完整三臂证明，且供回水独立；唯一一对反向主管臂共用原始LINE。文字必须重新证明属于该主管LINE。支路标注不反向作为主管种子。
2. 主管到三通之间的每个中间三通继续执行原校验。目标支路只沿已有源路径和原两臂弯头到达竖段，保留原根块、子线及Z接触；图中的省略标识不能当成源管线根块。
3. **必须检查同一边的全部原始路径是否还有管径或F标注，不能只查三通到当前目标的短区间。** 下游或省略另一侧有新管径、复合标注或未解决归属时，不能先把主管管径填到上游短竖段。先处理支路标注与变径范围；不擅自推定变径点。
4. 完整执行原有自动排气阀显示支腿归一化，并核对当前元件实例与归属；旧源CAD、主图和元件不改。不同主管候选值冲突、额外射线、不同源Z、无唯一主管、未证明的源线或连接均保持未知。
5. 只记录原边／路径／竖段及主管标注、真实三通和支路连续证据。水平最终属性仍取平面图，未知竖段长度仍留空；不新增节点、连接、整边管径或人工确认。

SH16批量筛查的保护反例：仅检查局部目标会产生26个候选，检查完整支路后只保留20个；E0063–E0066等含下游DN80或归属疑点的6个候选必须排除。图层0的Y型过滤器图形仍需独立源归属与图形证据，不能仅凭块名、外包框或更近距离排除。

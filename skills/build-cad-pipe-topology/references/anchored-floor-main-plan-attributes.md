# Whole-floor main attributes after anchored correspondence

Use `anchored_floor_main_plan_attributes.py` after independently checked whole-floor main correspondence. It replays that mapping and its original local source/graph owners. It produces source evidence; publication still needs a complete-parent fusion consumer, comparison and HIL.

## Annotation completeness before inheritance

Read the native source through the Chinese readability preflight. Reuse the ordered exploded-LINE F reader and consume its text/strokes before the scalar leader screen. Inventory every DN-bearing native text near the declared scope, including repeated labels. Bind each scalar to a unique native source LINE. Ambiguous, compound or system-qualified captions need their dedicated readers; do not select a convenient old seed subset or silently omit competing text.

Native same-system three-ray T evidence defines one opposite through pair. `through_source_DN_inheritance.py` propagates only through that pair; explicit edge labels stop incoming inheritance. Branch labels do not backflow into the main. Repeated equal labels retain separate evidence. Conflicting inherited values remain null with both source paths; conflicting direct values on one edge require source segmentation first. This helper does not replace the existing device-branch default owner or infer hydraulic direction.

SH16 08 is a protection case: the full scope has 22 scalar observations. Using only the older 12 seeds misses DN450 labels. The complete scan leaves E0038 and E0094 with 200/450 inherited conflicts. Neither maximum DN, nearest text nor historical guesses resolve their physical extent.

DN labels on an unmapped feeder may seed the network only through a uniquely selected T-contiguous native path. Verify that every selected label projects onto that path and replay its LINE coverage. Retain original path indices and the excluded remainder; do not cross an unaudited inline joint or claim the whole feeder DN, boundary or length is resolved.

## Native lengths and preserved values

Require a native floor title, explicit plan window and independent native dimension directions corroborating mm. Expand the window only with a new explicit policy and fresh source replay. Do not use global units to measure a detail view or infer unshown connections.

For existing qualified inline joints, replay their template/contact/path evidence, measure each uniquely covered native LINE piece, and preserve original path indices. Marker graphic spans and unknown interiors are excluded; installed whole-edge length remains unknown. No new edge or connection is created.

Every previously published whole-main DN and XY value must survive the new complete-source run. A changed prior value blocks publication for source investigation. Local graphs, vertical scopes and human confirmations are untouched.

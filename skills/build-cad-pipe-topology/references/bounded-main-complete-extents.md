# Complete already mapped bounded-main lengths

The bounded-main provider already owns correspondence, local DN and drawn plan
XY. Reapply `native_main_endpoint_extent.qualify` across its whole current cohort
before calling any missing complete length an unmatched pipe. This is reuse of
existing endpoint, source T, plan unit and metric readers, not new discovery.

`reconstruct-bounded-main-complete-extents` replays the complete provider
inventory and original bounded source owner. After an equipment-owner repair,
compare each selected old/current node-edge snapshot exactly. The current T
policy pins the genuine new graph hash; it does not pass an old hash for new
graph bytes. Recheck both native source paths and both Ts in both views, exclude
compound carriers, and independently recompute the actual plan metric.

Run `validate-bounded-main-complete-extents --extent-run RUN`. Only complete
horizontal T-to-T paths qualify. Gaps, projected circle offsets, unproved ends
and inline flexible interiors retain partial/unknown extents. Same-floor
vertical segments still take values from the axis drawing. Keep DN, mapping IDs,
components, source geometry and unknown installed/net lengths unchanged.

Use `refresh_bounded_main_complete_extents.py` and its
`validate-bounded-main-complete-extent-refresh --bundle VIEWER` gate. The new
extent context is nested under the original bounded owner; old bounded records
and source bindings remain exact. Its independent proof is required in both
properties and CSV. Compare every effective old field on every edge, preserve
vertical/member owners and annotations, and invalidate related semantic HIL.
Native wide/local context and real browser/export checks precede publication.

If a newly observed native compound declaration covers an old bounded carrier,
retain the old scalar as a superseded source observation, not a current member
value. Preserve the independently proved correspondence and drawn carrier XY;
withhold scalar DN and allocated member length until member identity is proved.
Publish the typed quarantine in properties/CSV using its own native proof;
never count it as a completed length or silently restore the old scalar.

A whole composite graph edge is not a source annotation fragment. Native compound
labels proposed for its horizontal arm must not automatically classify every
LINE in `source_handles`, including an orthogonal arm, as that compound carrier.
`compound_carrier_fragment_scope.qualify` can discharge only this unbound
orthogonal-arm proposal, requiring an existing direct local DN seed and a new
unique native text/LINE reading across the selected interval. It transforms the
TEXT baseline through OCS to WCS; parallel labels, unsupported text, missing
direct evidence or competing native pipes retain the member barrier. No DN value
or pipe-level literal is used to choose correspondence. True horizontal compound
controls remain protected. This is source-fragment scope, not proof of physical
pipe multiplicity or elevation units.

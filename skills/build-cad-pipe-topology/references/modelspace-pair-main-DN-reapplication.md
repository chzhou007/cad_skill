# 将既有成对标注归属接入主管管径继承

使用 `reconstruct-modelspace-pair-main-DN` 与 `validate-modelspace-pair-main-DN`。
复用原 `native_paired_caption_geometry`／`native_paired_end_labels` 的完整供回水
几何归属，不按管径或括号值选管。F优先、第三根平行管、重复LINE、文字变换与
源Z检查仍生效。水平文字可作为11图竖段管径种子，不能成为水平最终值或长度来源。

先把独立归属的文字定位到一段原始LINE及唯一原始图段。沿同一LINE扩展到其他
原图T切分段时，必须调用原 `through_line_evidence`，重算每个中间T的三臂、
直通源线和系统；不能只因源句柄相同就跳过这些证据。端外文字若没有唯一实际
图段锚点，仍保留未知。原直接标注和成对标注同等采用这个入口。

同一逻辑边转弯后可以包含不同LINE与不同管径。三通当前接入的那一根原生LINE
已有独立标注时，优先该源域，不能将整条逻辑边上的远端标注都当成同一范围。
同一LINE内部的不同值、未识别新标注、复合标注和F仍阻断；不能按近远或数值
相等强选。不同原归属读取器对同一文字给出不同源管时，入口必须报冲突。

共享适配器只在原主管读取器的候选选择位置接入这个源域规则；原几何、源Z、
两臂弯头、三通、主管两侧完整源线及整条支路的标注屏障保持。上游代码接口
发生变化时适配器拒绝运行，不能静默套用失效补丁。

一次源图回放同时覆盖当前未知竖段和全部已采用的主管三通继承记录。旧记录
必须重新获得相同管径；未重证或值冲突时阻断发布，不以旧快照一致代替正确。
仅追加原未知竖段的管径，保留所有旧属性、设备、元件、批注与未知长度。

SH16回证含二层回水支路、二三层主管竖向转折，以及此前被保留的E0501：
原候选DN250仍未采用，新值来自独立成对归属的本地主管DN300；并非放松变径屏障。

混合边须按方向分别互证：同一边的平面水平DN200与11图水平DN200可以一致，
而该边另一竖段从11图读取DN300。这不是同范围冲突；不能把两段合成一个管径。
变径位置和未绘接管仍需源证据，不能由这个数值组合自动推定。

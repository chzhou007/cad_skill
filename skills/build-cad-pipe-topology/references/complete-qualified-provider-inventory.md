# Inherit all qualified cross-view providers before new discovery

An early batch mapping is not the complete current correspondence inventory.
Later bounded mains, ordered child runs, owner repairs and compound-member
providers may already cover an edge that the early batch calls unmatched.

Run `qualified_crossview_provider_inventory.py --manifest MANIFEST --output NEW`
before reusing main/branch discovery. `--verify-output RUN` independently replays
the current qualified viewer, native owner extension and original axis direction
reader, checks the fixed inputs, and reconstructs the inventory.

The manifest pins the viewer manifest, native axis/raw axis graphs, all three
current plan graphs, early batch, owner extension, native direction result and
current horizontal attribute frontier. Output preserves every provider observation
and original mapping ID. Overlapping ancestor observations do not create another
physical edge or writer. New providers require an explicit adapter.

Use the native `plan_Ts`/`axis_Ts` pairing, not display edge direction. Reject
competing ordinary anchors. Keep physical member graph nodes separate: a shared
projected canonical T may represent different member nodes, so member anchors
cannot be flattened into the local-plan bijection. Main/detail aliases likewise
need their own coordinate-domain proof.

The result is a discovery input and completeness inventory, not new native path,
DN, length or human approval. Reapply the existing source path/T/metric rules to
any new candidate. In particular, a bounded path rejected for multiple native
LINE witnesses stays pending. Do not widen a canonical family projection beyond
its proved scope or treat overlapping source entities as one physical pipe.

Only horizontal portions enter plan mapping. All vertical portions, including
same-floor rises/drops, use the axis drawing. A known correspondence with missing
inline length or source DN is an attribute task, not an unmatched path. Unknown
mixed-edge horizontal coverage remains unknown instead of using the whole-edge
incomplete count as a plan backlog.

Use `reconstruct-third-arm-crossview-batch` and its independent validator after
the full current legacy-provider inventory. Re-execute that original owner in
its pinned complete runtime; retain every old observation, member, component and
attribute. A previous candidate screenshot or a saved pass flag is not a parent.

When equipment-owner reconstruction has changed a plan graph, reuse
`source_stable_junction_reapplication.prepare` with the pinned native transition
before interpreting an old configuration/hash rejection as a source defect.
Do not replace the old configuration hash directly or discard its source bounds.

Inspect the native entity type behind `source_insert_handle` before using a
nested-ray fallback. On legacy standalone omission edges this field can name a
`DIM_SYMB` LWPOLYLINE marker. It is not a pipe INSERT. Reuse the original
`partial_native_line_coverage.intervals` to report a source gap separately;
neither a small gap nor an existing graph T supplies missing source evidence.
The T306 regression preserves its 2.35484-unit source gap without changing
connectivity, tolerances, lengths, or the previous floor-label correction.

At an independently mapped real T in each view, two one-to-one incident source
paths can constrain the third arm. Preserve the exact mapping IDs and verify
that a partial named path actually reaches this T. Enumerate the entire cohort
before using the constraint. Existing member providers are already matched;
their axis edges cannot be rematched through an ordinary drawing carrier.
Conflicting remote anchors, competing node/edge identities, unproved remote Ts,
fragmented carriers and mixed/unknown axis paths remain with their original
member, local reconstruction or segment owners. Node IDs such as UT do not
determine node type: inspect the current source-repaired node and native rays.

For a qualified pure horizontal interval, replay both endpoint native Ts and the
complete source LINE path in each view. Retain source system isolation and the
original direction policy. Never select a correspondence using DN, length,
nearest geometry, component equality or the apparent shape of a closed loop.

A source-detail mismatch needs primitive evidence. Reuse the complete known
ball-valve signature, finite WCS flange contacts and unique native pipe/local
graph ownership; keep mirror/negative OCS behavior and unknown parameters. The
plan schema adapter reads existing source-covered segments without changing the
original graph or pretending a drafting marker is pipe. Reconcile every selected
instance and every uniquely owned source glyph. Unclaimed, multiply claimed,
unsupported or ambiguous target components block this exception.

When native sources really draw different valve counts, the unique T/path
relation may be recorded as **topology only, source-detail difference open**.
Preserve both component populations, forbid cross-view component merging and
attribute adoption from that relation, and expose the discrepancy for source
comparison/HIL. Do not remove an extra valve or complete length to force agreement.

Raw drawing-carrier cycles and reconstructed physical-member graphs are different
domains. A raw biconnected component size is not a global two-view correctness
test. Compose only explicitly source-proved member interfaces before broader
cycle comparison; coordinate overlap and shared axis IDs alone do not justify
joining physical members. This batch asserts local source scopes only.

every marker before HIL. Group a shared expression-scope conflict into one
wide/local source review rather than asking once per edge. Source-interface and
axis-marker counts are not physical equipment counts; locator IDs are not

the water-fluor heat-exchanger region, while drawing 11 has 14 marker expressions.
Keep that unresolved scope difference separate from the repaired configuration

# Expert repair evidence and batch handoff

For expert feedback, verify source/dataset identity, retain the original note and locate the native source region. Summarize the defect mechanism and affected family/shared rule before expanding repair scope. An error example is evidence to investigate, not authority to guess missing connections elsewhere.

Use source classification before family interpretation, then equipment/material reference recognition before ports and graph construction. A verified physical source group and hydraulic supply/return classification are independent facts. Keep service unknown when continuity alone is proven. Read source-group-crossovers-v1121.md for opposed tails, crossing witnesses, exclusions and calibrated acceptance.

Normalize verified geometry before equipment ports, T detection, adjacent-edge tracing and component assignment. After normalization, recompute these dependent products. Crossovers preserve each own pipe and do not connect the crossed pipe or establish elevation. A nearby real branch remains eligible for T detection. Do not delete every degree-two T: distinguish a verified overshoot from a missing branch. Missing edges/nodes can change counts legitimately.

Audit every accepted straight span against one complete final edge and both source tails; checking that two disconnected handles exist is inadequate. Include accepted spans found in normalization audits even if that family did not previously emit a coverage file. Record discovered/rejected/pending reasons. A proven crossing omitted solely because source service/group configuration is missing must be resolved or blocked, not disguised as a generic open endpoint.

For a shared fix, return per-task fresh reconstruction, source/profile/code identities, physical change explanation, component identity/edge ownership and port checks, and old/new ID mapping to the orchestrator. Compare full paths for parallel edges. Preserve pending evidence and source enrichments with provenance. Counts alone cannot establish equivalence or source completeness.

Large equipment remains physical equipment even when contacts/parameters are incomplete. Keep required resistance parameters explicit; only proven meter measurement branches may be simplified in a separate calculation projection. Current-layout-only scope requires native contact evidence; neither a nearby pipe, building outline nor another schematic establishes a port.

Architecture is a separate owner: source entities may be referenced by both branches with their evidence, but pipe gap/overshoot rules never operate on architectural doors/openings. Never import building categories as pipe connections. Return to the orchestrator without recursively starting another pipeline or final viewer.

Use existing tests for unknown-service crossings, near junctions, native components/ports, source fidelity, parallel edges and historical/native fixtures. Include relevant negative families; archive a source-justified baseline separately from the immutable benchmark. Report supported-family coverage and remaining unknown CAD semantics honestly.

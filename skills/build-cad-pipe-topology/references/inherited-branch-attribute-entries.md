# 支路属性读取继承已有端口、方向与归一化规则

适用于主管范围与平面管径已有完整源图回证，但属性入口仍被旧几何读取方式拦住的支路。先严格读取中文，再重放当前完整父查看器、原生主管范围和当前竖段父证明。保持原图、当前图、旧值和既有设备对应。

## 三类入口要分别处理

**绘图端口几何与完整路径分开证明。** 同一省略标记的供回水端口必须保持完整清点和系统独立。另一根管的远端路径未见证，不应使本端口已有的原生端点几何失效。`native_marker_endpoint_geometry` 优先返回原完整读取器的原结果；失败时，以每根实际末端LINE的源片段组成只读端口切片，重新调用原来的完整标记/接触清点和30绘图单位标记定位规则。切片边界不是真实节点，也不证明完整支路或远端设备。完整原支路及主管三通随后仍单独重跑原校验。

**明确水平区段不被同边未知方向区段整体遮蔽。** 独立完整对应的同一范围内，平面下部成员及所有剩余主管区段的管径均已证明一致时，`partial_uniform_main_DN` 对原来未采用的边重跑完整原生路径、XYZ弯头、全支路管径及F标注屏障，只发出原方向表已经确定的水平区段DN。原来未确定方向的区段不重分类、不赋值；竖段仍归11图。高部成员前缀不得借用下部管径，不能因方向微差放宽原阈值或推导长度。

**连接归一化必须进入属性读取。** `normalized_attribute_source_context` 重新执行原始归一化审计及原生三射线证明。仅对精确对应的“原生源段尚未见证”区段，向旧DN读取器提供有证据的私有语义坐标；保留原始LINE、原路由状态、归一化作用域及未知断口长度。竞争源线、超限缺口、不同Z、新增源接触或审计变化仍拒绝。不能把私有读取格式写回为原始LINE证据。水平最终DN来自平面；竖直DN另用11图的原注释/成对归属、主管三通与完整支路屏障证明，不能从平面DN推入。

## 共享入口与检查

- `pipeline.py reconstruct-inherited-branch-attributes --manifest ... --output ...`
- `pipeline.py validate-inherited-branch-attributes --verify-output ...`

完整候选批量运行；旧已通过支路的源几何、主管归属、标注屏障和端口证明必须保持，仅允许“上轮空值、本轮已采用同值”的历史状态字段变化。既有关键能力退化须阻断发布。新源结果、当前查看器采用、实际导出和HIL分别验收，源重放不自动更新最终查看器。

源重放完成后，使用[独立水平与竖段证据的正式发布入口](../../visualize-cad-pipe-topology/references/inherited-branch-entry-publication.md)。新增11图竖段写入独立来源字段，不能伪装成旧导出中已经存在的证据；未确定方向的主管只展示已确认水平区段，不能直接填整边管径。

测试包括原标记成功结果字节不变、完整端口清点、旋转镜像、坏伴随路径不隐藏有效端点、源线/标记竞争、原生XYZ、未知方向保留、变径/F屏障、旧值保护，以及归一化后DN读取但原始缺口仍未见证且物理长度为空。SH16回证样本覆盖E0224、E0330和T306/E0582；LF20在SH16规则稳定后回测。

# 管径读取继承已识别元件与已归一化弯头

历史设备／元件识别和几何归一化必须进入属性读取输入，不能只在最终拓扑中生效。使用 `reconstruct-typed-inline-attribute-DN` 与 `validate-typed-inline-attribute-DN`，在完整当前未知竖段集合上复读原生标注，并保留原图、原图谱、元件实例及旧属性。

已识别元件的中性图层0线条不自动视为另一根管道，但不能仅按块名或外包框排除。入口要求历史原生类型映射、图例目录、原完整块指纹与当前一致，完整嵌套实例和叶图元可追踪，并且唯一元件库存及当前同根块管线归属一致。当前只支持已登记YS完整直线原型；未知图形和所有实际管道仍参与原有半字高竞争判定。保留完整中性图形人口与每条排除证据，不删除元件或推定物理端口。

弯头续传须复用原 `trim_elbow_overshoots`、历史配置和原容差：10个绘图单位上限、0.1相对长度上限、20度最小夹角及0.2原接触容差，不为本轮放宽。每个私有读取投影须匹配原拓扑归一化审计的源实例、原端点与语义端点，再核对同Z两条原生LINE及真实两臂；源文件、真实T和现有路径不改。未证实额外支路或重复源线仍阻断。

然后运行原直接标注、F优先、旋转镜像、源Z、唯一原边片段、两臂弯头和新管径屏障读取器。已证明的管径仅进入原竖段；水平属性仍取平面图，物理长度、安装长和未知阻力参数不赋值。语义改变不继承人工确认，旧批注保留。

SH16回证：1548A／1548C／1548E／15490的竞争线属于已识别YS实例，原始直接读取器得到4个DN80竖段。其余4段在原拓扑已裁掉2.1003887绘图单位的弯头微越界，但旧属性读取器仍读原尾线而误见三臂；重放原归一化输入后恢复两臂续传。它们是既有元件及归一化能力的入口补齐，不是新识别出8根实体管。

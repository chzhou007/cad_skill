# Apply the inherited named-interface readers to a whole source batch

Use `batch_native_named_interfaces.py --manifest MANIFEST --output NEW`, then
`pipeline.py validate-native-named-interface-batch --batch-run NEW`. Each drawing
declares its source/graph hashes, plan or axis family, native text/leader layers
and optional hash-bound external policy templates. Discovery inventories all
matching modelspace TEXT/MTEXT proposals; unsupported/nested forms are not
silently accepted. This is source-annotation replay, not a local topology-owner
reconstruction or cross-view acceptance.

Reuse `native_named_riser_evidence` for every candidate, and the existing
`native_external_pipe_destination` / `native_external_port_destination` readers
for external groups. Original external templates stay immutable. New policies
bind the actual current graph and are checked again against native text,
underline, leader, marker, pipe and node/port membership. A rejected external
provider cannot fall back to a weaker named-label interpretation.

Keep these source roles separate: plan riser circle, axis native pipe target,
plan external frontier and axis external port. Identical CHWS/CHWR names at
different source roles, floors or repeated views do not prove correspondence.
Store the observed named DN and original native evidence, never a whole
horizontal-edge DN, a physical length or an inferred connection. In particular,
CHWS2 DN450 on a plan riser circle does not resolve a DN450/DN200 horizontal
approach. The existing named-approach scope guard remains active.

Independent source failures stay in the complete per-text outcome partition
while other drawings/scopes finish. Before HIL, route deterministic target or
provider gaps to extraction. Names and typed interfaces supply candidates for
the checked path/network owners; they do not replace those owners' independent
equipment/network anchors or prove shaft co-location.

`--verify-output NEW` re-reads every source and current graph, repeats discovery
and the original native providers, and compares the complete result. Keep
source-annotation replay, topology replay, mapped paths, attribute fusion and
HIL as separate statuses. No old pass flag or graph-hash edit substitutes for
this source reading.

# Apply reconstructed riser header intervals

After native header reconstruction, consume the original independent cycle-gate
owner again. `riser_header_interval_application.py` binds the exact plan, native
axis, raw/rendered axis, source CAD, current viewer and all parent proofs. Run
`pipeline.py reconstruct-riser-header-interval-application --manifest ...
--output ...`, then `validate-riser-header-interval-application --application-run
...`. This adopts member correspondence, not an ordinal lower-terminal match.

Reapply original native path coverage, floor-plan unit dimensions, plan length
and exact-touching-subdivision readers. A gate-to-circle member can have a
complete horizontal centreline. A circle-to-riser member keeps a known drawn
plan projection and unknown full length when a riser-symbol offset/connector
is not proved; never add its radius or fill the connector with zero. All vertical
domains, including same-floor rises, remain owned by drawing 11.

For DN, select the plan compound declaration by the independently read literal
member level and crosscheck the native axis caption. Reuse the old direct/F
annotation guard on a read-only projection excluding only compound captions
already owned by that exact member declaration. Preserve F priority, unsupported
annotations and every other direct DN conflict. A conflict leaves DN unknown
without discarding an independently qualified metric.

Old cycle metrics may be restored only after native atom-origin refinement proves
that every old barrier came from another arm and no actual compound carrier
remains on the selected source paths. Replay the original metric owner too.
Do not globally disable the historical barrier or delete its evidence.

Publish with `refresh_riser_header_attributes.refresh`; validate with
`validate-riser-header-attribute-viewer --bundle ...`. Retain the original guarded
context as history. The new context clears only exact native-qualified scopes;
malformed/stale context leaves old holds in effect. All unrelated old effective
values, vertical domains, graph/component payloads and annotation files remain
exact. New CSV fields append after the existing prefix. Verify native rendering,
actual Chinese UI and actual exported CSV before updating completion counts.
The separate recovered-component inventory is not silently written over the
unchanged legacy component payload; its viewer/index adoption remains explicit.

Finally rebuild the complete provider inventory with the member namespace
preserved. An adopted member with unknown connector length is a metric task,
not an unmatched path. Technical success never inherits human confirmation.

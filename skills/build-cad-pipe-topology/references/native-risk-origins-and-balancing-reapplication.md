# Native risk origins and balancing-valve reapplication

Two omitted uses of existing readers must be checked before treating a source
comparison as a new CAD ambiguity. They have separate outputs and acceptance.

## Compound text on one arm of a bent edge

The original `carrier_risks` grammar and LINE-lineage barrier remain the base.
A multi-arm edge candidate does not prove that every source LINE on that edge
owns the compound caption. `compound_carrier_atom_origins.refine` reruns the
same annotation reader on each original path atom and requires one modelspace
LINE witness present in the original source handles. It removes an old origin
only when all atomic candidates belong to other source LINEs. Real parallel
compound captions remain barriers across their LINE lineage. Unsupported TEXT
transforms, duplicate source lines and F/leader ownership retain the old barrier.
A drawing with no compound declarations has an explicit empty result.

Run `pipeline.py reconstruct-compound-carrier-atom-origins --manifest ...
--output ...`, then `validate-compound-carrier-atom-origins --origin-run ...`.
Manifest inputs are hash-bound `plan_source_N` and `plan_graph_N` for each floor.
This refines risk origins only: it does not restore a held mapping or scalar DN.

## Known-family balancing valves omitted by an entry point

`native_balancing_valve_recovery` reuses the unchanged six-LINE bow-tie and
adjustment-stroke signature in `native_inline_coordinates`. Derive flange ports
in WCS after block transforms. Raw INSERT origins can be far from the symbol.
For the known `平衡阀` family, require both ports and the centre on a unique
same-Z native service LINE and a unique continuous graph segment. Use the pipe
system as evidence, retaining component-layer discrepancies. A circle, nearest
edge, visual resemblance or component layer alone is not sufficient. Missing
or duplicate native pipe/graph ownership stays unresolved and in the inventory.

Run `pipeline.py reconstruct-native-balancing-valves --manifest ... --output
...`, then `validate-native-balancing-valves --valve-run ...`. Inputs are
hash-bound source, graph and original components CSV. Prior component rows and
IDs remain exact; new IDs use stable source handles. No resistance value is
invented. This inventory is a new version, not a manual edit of old components.
Revalidate affected component profiles, member edges and mappings before viewer
publication; preserve original annotations as history and invalidate changed
semantic confirmations. Unknown valve parameters and real gaps remain unknown.

Tests cover bent/parallel captions, F precedence, unsupported source transforms,
native duplicate ambiguity, full/partial signatures, rotation/mirror/negative
OCS and block offsets, crossings and source Z, unique ownership and idempotence.

# Bent main paths between independent mapped junctions

Use `rebuild_anchor_bounded_main_batch.py` when the old residual degree-two
chain reader stops at a real T with an unmatched off-path branch. Preserve the
old reader and its stricter whole-network/straight-corridor contract unchanged.

The new scope is a complete region of eligible unknown same-floor, same-service
Ts, with **all** incident independently mapped junctions present as boundaries.
Keep every edge among those nodes, including existing writers and parallels.
Use the inherited bridge-path verifier; cycles and parallel routes remain
blocking. A path cannot pass through another mapped boundary internally.
Reject multiple regions joining the same two anchors. This establishes a path
inside that semantic region, not global uniqueness outside its boundaries.

Require unique paths in both views, fixed independent endpoint orientation,
equal internal native T counts and matching per-interval component types/counts.
DN, apparent distance, drawing ratios, label similarity and shortest-path choice
cannot select a route. Preserve unsupported component kinds literally. Re-read
every original T (including its off-path arm) and visible pipe segment; use the
inherited horizontal-domain verifier to reject mixed/vertical axis paths.

Overlapping anchor-pair observations may corroborate the same interval only if
all node and edge identities agree. Deduplicate them into one writer per pipe;
never count observations as additional mapped edges. Competing internal node
identities remain explicit. Derived Ts do not seed their own proof or enter
discovery until a subsequent independently verified version.

The producer replays the original complete current batch, qualified ordered-main
proof and every current local plan owner, then scans all three floors. It does
not bypass plan topology or change local connections to match the axis. Native
plan metrics report drawn pipe XY only; unknown fitting interiors, unshown
connectors, physical installed length and net cut length stay unknown. This
stage does not fuse attributes or establish an unmatched off-path branch.

This rule can locate a bent DN300 main's missing endpoint without assigning a
compound DN300/DN200 carrier to one scalar. The confirmed two-pipe meaning is
retained, while a carrier with unequal internal branch counts still needs its
member topology reconstructed. Equal component totals never excuse that gap.

Run `pipeline.py validate-anchor-bounded-main-batch --batch-run RUN` for an
independent replay. Technical pass remains separate from fusion, source Pair
inspection, actual browser/CSV, expert acceptance and LF20 generalization.

## Inherit the current native T reader, not only the old function name

Use `native_current_junction_reader.make_reader` with the exact source/graph
configuration already used by the current full-plan reader. It privately
composes the unchanged projected-circle, local-detail, normalized circle-lineage,
user endpoint and confirmed-overlap adapters. Read their original source parents,
expert extents and receipts. The routine reads geometry only: it neither runs
DN inheritance nor uses DN to select a match. The original failure conditions
and branch/ray ownership guards remain. Unknown geometry errors do not fall
through to another rule. A bare historical `native_tee` name is not proof that
all historical T capabilities are active in a new pipeline entry.

The complete source dispatcher also reads wave/main-cohort junctions and
expert/calibrated coincident-circle incidence through their original providers,
before the ordinary T chain. Incidence proof does not resolve physical identity
of duplicate LINEs. If the unchanged path reader reports multiple native LINE
witnesses, retain that barrier; do not pick an arbitrary handle, widen tolerances
or claim that the source adapter establishes a unique physical carrier.

## Native metric dispatch after source correspondence

`native_main_interval_metrics.measure` first tries the original ordinary plan
projection reader. Consecutive attribute-path arrays whose endpoints are exactly
equal may be coalesced in an explicitly hashed read-only projection. There is no
tolerance snap and no added segment. Keep original segment/path indexes and
source coordinates in the resulting pieces. This projection may precede the
original inline/crossover reader when touching array subdivisions coexist with
real excluded crossovers. Replay every actual crossover under the old rules;
never count its graphic span or unknown component interior as physical length.

Metric extraction failure does not destroy a separately proven correspondence.
Record the metric as unknown and retain its exact reason, reader attempts and
mapping scope. Missing implementation fields still fail instead of becoming
expert questions. Test this dispatch on native selected paths before expensive
complete-parent replay, then run the full source gates before publishing.

parent. Replay the native bounded-main owner, match every raw/rendered child and

drawn-branch contexts with their exact source/version bindings. State retained

component assignments and original annotations. A new effective dataset identity
invalidates semantic HIL confirmation.

unknown whole installed length. Actual common property/CSV readers consume the

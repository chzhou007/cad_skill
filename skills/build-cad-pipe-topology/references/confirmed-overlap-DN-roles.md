# Carry the original confirmed-overlap feature into T and DN reading

Use `rebuild_confirmed_overlap_full_plan_DN.py --manifest INPUT --output NEW_DIRECTORY`
and `pipeline.py validate-confirmed-overlap-full-plan-DN --batch-run DIRECTORY`
when a checked local graph retains `user_confirmed_overlap_connection`.
Preserve all previous local inputs, annotation/review scopes and circle readers.
Each applicable plan adds `confirmed_overlap_owners`: a list of entries with
hash-pinned `policy`, `evidence_manifest`, `parent_graph` and `parent_devices`.
These are real original owner artifacts, not regenerated parent snapshots.

`native_confirmed_overlap_rays.py` reuses
`repair_confirmed_overlapping_branches.apply` on its exact original source,
graph, component table and user evidence. Both `native_circle_rim` and explicitly
confirmed `user_confirmed_hidden_overlap` retain their original contracts. Bind
the resulting native circle, current T, original repair record and branch scope
before reading DN roles. Current main arms must independently lie on the same
unique native main LINE in opposite directions. Extra native center contacts,
stale evidence, mixed systems or unsupported branch orientation stay barriers.

The final segment of a hidden-overlap display connector can coincide with the
main. Reading that segment as a physical branch ray destroys the original T.
Use the actual original branch LINE orientation only for this confirmed DN-role
contract. Record its true native coordinates and the distinct logical contact;
never translate it into a newly asserted native pipe or measured connector.
The two source-proved main arms remain the through pair; this is not hydraulic
direction. A nearly collinear original branch needs separate evidence.

Recompute DN on the complete plan using explicit source labels, branch overrides
and all prior guards. Preserve source XYZ as drawing evidence; a confirmed
plan contact does not turn Z into height, or the display route into physical
length. Keep hidden connection length unknown, supply/return independent,
circle colours unchanged, ordinary crossings protected and HIL pending.

The fallback applies only to the original explicit overlap schema and its
missing/ambiguous center-ray error. It cannot join arbitrary broken LINEs.
Local connectivity is still owned by the original rebuild, not this read-only
T/DN adapter. Changed inherited scopes require subsequent correspondence and
attribute recomputation; do not edit a final fused graph to add values.

Tests: `test_native_confirmed_overlap_rays.py`,
`test_confirmed_overlap_full_plan_DN_gate.py`, original overlap, user-corner,
split/merge, ordinary crossing and complete DN suites. Full SH16 native replay,
axis fusion, LF20 and human acceptance remain separate evidence.

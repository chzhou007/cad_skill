# Inherit legacy named boundaries and riser scopes before discovery

Run `reconstruct-legacy-named-provider-inventory`, followed by
`validate-legacy-named-provider-inventory`, on the complete current contact
provider. Pin its full immutable runtime snapshot, current rendered/local
graphs, the original local graph versions, native sources, current T-reader
configuration and original external-destination policies. The fixed worker
executes the original complete provider owner; a stored pass flag is not enough.

Attribute-context providers and older graph-root providers are separate input
families. Explicitly inherit external feed scopes, named floor-riser approaches,
upper and lower horizontal riser segments, and named network approaches. Check
that root records agree with their current edge attributes, retain each original
mapping ID and extent, and require original/current edge topology, paths and port
identities to agree. Changed local structure returns to the original mapping
owner rather than accepting a source fragment as proof of a new correspondence.

Replay current native path fragments and current true Ts using existing readers.
For common external markers, retain the original marker-aware path reader and
replay each named port and native caption leader. Exclude its centre display
span and separately confirmed inline gaps; never remove the marker handle merely
to make a fragment projection pass. A common marker does not connect services.

Named boundary ports, named riser interfaces, horizontal segment scopes and
physical-member scopes retain distinct domains. Only independently replayed real
plan/axis T pairs may augment the ordinary anchor map. A plan RIF circle cannot
become an ordinary T by pairing it with an axis riser T. Conflicting identities
block inheritance. Preserve every prior provider observation and member domain.

Rebuild the frontier after inheritance. An existing partial correspondence is
an attribute-completion task, not a new topology-matching question. Local scope
DN or drawn XY does not complete a whole edge across a marker, connector or
inline interior. This stage changes no graph, physical value, component owner,
vertical source route or human acceptance. Afterward batch discovery against the
complete updated inventory; native source qualification and attribute adoption
remain separate stages.

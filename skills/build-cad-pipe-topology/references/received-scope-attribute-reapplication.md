# Reapply attributes after a newly qualified reviewed range

Use after a received source-bound connection reply enables a complete plan/axis range that an older DN or metric run held. Source correspondence and actual viewer adoption are separate outputs.

## Native batch

Run `pipeline.py reconstruct-received-scope-attributes --manifest <manifest> --output <directory>` and `validate-received-scope-attributes --verify-output <directory>`. Pin the original uniform proof, newly replayed received-scope proof, actual current manifest/effective values, exact component-overlay parent and current provider. The verifier replays original source, member, interval, caption and native unit owners before applying their unchanged kernels.

Keep full range correspondence and independently measure the complete native plan LINE fragments. If original axis direction rules hold an edge, do not change their tolerance or infer verticality from screen appearance. A real contiguous, independently source-checked horizontal attribute prefix can stop before that edge. Preserve the full original route and explicit direction hold; do not skip interior edges or invent a new endpoint correspondence. Keep every known DN conflict, F/new-caption barrier, system/floor/source/geometry constraint and complementary drawing11 vertical domain.

A group metric is the known drawn plan LINE sum with omitted spans retained. It is not a complete installed length. Unequal interior branch counts do not prove ordinary node pairs or a division among individual axis edges. Export each metric once per scope identity, never as an edge length.

## Current viewer

Use `refresh-received-scope-attribute-viewer --parent <current viewer> --output <new viewer> --proof <native proof> --parent-provider <actual provider> --templates <templates> --port <port>`, then `validate-received-scope-attribute-viewer --verify-output <new viewer>`. Preserve older context roots and their serialized CSV evidence. Add separate received-scope roots through private typed views of original checked constructors. Only unknown whole horizontal DN may fill primary scalars; mixed edges get scoped horizontal evidence only. Keep all lengths, vertical sources, ordinary/member identities, component instances and annotation history.

Verify Chinese properties in the actual app, both complete network CSV exports and the shared metric JSON download. Compare old columns by stable edge identity; BFS row order can change with selection. Recount missing attributes from the actual facade, distinguishing DN-only improvement from both DN and length completion. Preserve source/schema gates; escaped template strings must still render Chinese. Technical adoption does not inherit human acceptance.

Tests: `test_reapply_received_scope_attributes.py`, `test_refresh_received_scope_attributes.py`, `test_received_scope_attributes.mjs`. Cover contiguous stopping, original direction/known-DN/endpoint/geometry rejection, private source namespaces, mixed-domain protection, old-source and length preservation, count-once metrics, held directions and unchanged provider identities.

# Native main continuity takes precedence over geometric opposition for DN

Use `rebuild_main_continuity_full_plan_DN.py --manifest INPUT --output NEW_DIRECTORY`
and `pipeline.py validate-main-continuity-full-plan-DN --batch-run DIRECTORY`.
This version retains the original local inputs and all previous source-reader
configuration. Historical v4/v5 DN batches remain intermediate evidence;
they must not be promoted for confirmed corner-main cases without this check.

A mandatory combination control is a bent native main labelled DN200 and a
reviewed rim-ending branch labelled DN80. The other native main child inherits
DN200. The small branch must not seed either main arm. Geometric opposition
alone selects the wrong pair when the original main turns at the T, producing
false conflicts and false branch backflow. A new explicit DN on the second
main child still defines a change boundary.

`source_main_DN_continuity.py` preserves all original source/graph/T/ray/seed
validation. For the independently replayed original user-circle corner schema,
the two native center arms and exact original main-child lineage establish main
continuity; the original rim arm establishes the branch. Verify the real parent,
screen, raw reply and current native proof through the existing readers first.
The new role retains the geometric opposing pair as evidence while recording
`role_basis` and `original_main_source_edge`. Native directions, connectivity,
coordinates and physical metrics are never changed to force a result.

This is a bounded source contract, not an arbitrary edge-ID override. A plain
T still uses the original unique geometric pair. Missing/stale original main
records or a mismatched rim/center classification fail. Keep explicit labels,
branch overrides, unknown connectors, supply/return isolation and every prior
circle/overlap/wave reader. Role changes invalidate dependent DN scopes,
correspondence attributes and affected HIL; they do not invalidate the original
answer confirming local connectivity.

the correction, branch-only no-backflow, rotations/mirrors, explicit main DN
changes and exact ordinary-T preservation.

# Complete-cohort source support for coincident LINEs

Use this after the current complete provider inventory and the existing bounded
main rule find a unique two-view route, but native coverage is blocked by several
coincident modelspace LINEs. Reuse `native_canonical_main_family_view.project`,
the original current-circle T reader, bounded main discovery/proof and native
metric readers. This extends their supported reading domain; it is not a new
pipe-count or nearest-line heuristic.

## Preconditions and reading domain

1. Recheck the complete current provider, including all ordinary and member
   observations. Existing writers remain reserved. The fixed SH16 parent may
   use the separate content-checked artifact entry below; a receipt by itself
   never substitutes for current dependency checking.
2. The complete duplicate native main family has the same XYZ and style. Every
   native circle on it has a current, source-replayed same-system T, one labelled
   equipment branch in each view and an existing independent T correspondence.
   Require at least three distinct equipment identities and cover the entire
   circle population. Missing/unmapped circles or conflicting branch identities
   block the cohort.
3. Consecutive equipment anchors have unique native main intervals in both
   views and qualified existing interval observations. Original native label,
   circle, through-ray and expert-control evidence is retained. Reuse the old
   canonical provenance reader to qualify the main family.
4. A per-path source observation may present one representative geometric
   witness to legacy unique-LINE readers, retaining the complete original audit,
   every witness, the cohort ID and private projection hash. It never rewrites
   the CAD, original graph, source entity identity, or original T reader.
5. A cap support interval must meet that member at one common native XYZ bend.
   Coincident cap copies may have unequal tails; read only the selected common
   interval. Preserve the tails. Missing spans, different Z/style, multiple
   qualifying members and compound-carrier barriers stop this mode.

## Batch commands and outputs

`reconstruct-equivalent-member-bounded-batch --manifest … --output …` runs the
native source owner and independent validation.
`validate-equivalent-member-bounded-batch --batch-run …` rechecks the same pinned
inputs and recomputes its output. The manifest binds the complete parent viewer,
provider, source graphs/DXFs, current T configuration, native atom/component
proofs, unit policy and inline template. Project family handles remain explicit
configuration; algorithms and negative cases are shared code.

The batch retains original bounded-route pending reasons and stable new mapping
IDs. Match without DN or length ratios. Known visible projection and complete
T-to-T centreline length are separate fields. Crossing omissions, inline
interiors, explicit incomplete-length metadata and unshown connectors retain
unknown complete lengths. Mixed/vertical segments stay with drawing 11.

This source gate does **not** publish a viewer or claim new DN. Apply the existing
native plan DN owners to these independently established scopes next, then
publish a versioned attribute context and inherit it into the complete provider
inventory. Verify actual browser/CSV values and preserve historical annotations.
Technical source qualification is not HIL acceptance.

SH16 fixture: floor 3, supply `12E28/1473F`, return `12E29/14750`, six native
equipment/circle branches per service. This explains the old coverage failure
without deciding whether the original duplicate entities are copies or physical
pipes. LF20 must independently satisfy all preconditions; do not copy SH16 IDs.

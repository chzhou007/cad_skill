# Named upper-floor correspondence on mixed-edge suffixes

Use `match_named_riser_floor_segments.py` when the current axis edge includes a
verified cross-floor vertical segment followed by an upper-floor approach to
an existing network T. The floor plan must have a native named RIF approach to
its network T and one existing bridge edge to an independently checked device
service T in each view. Require both services of the same device and floor.
This mode supports a nonplumb upper suffix; lower-floor and longer bridge
chains remain outside its current contract.

Replay the native branch inventory, through-riser scope, exact-touching plan
scope and main-view named leaders. Reuse inherited display-leg normalization
to identify the one upper bend of the named column. Repeated detail names,
same DN, geometric proximity and an apparent shaft position cannot choose a
column. Preserve original XYZ and the whole existing vertical scope.

At network and device Ts, replay all three native rays and require one unique
opposing pair. A through pair may use one native LINE, or two native LINE
endpoints meeting at the existing T with matching XYZ. The approach must be
the network T's third arm; its bridge must reach the independent equipment T
through its main pair. Retain historical circle-rim evidence for the device
branch. A plan XY contact, different native Z, unknown T, ordinary crossing or
wrong branch role cannot satisfy this contract.

Output two records per service: RIF approach and existing network-to-device
link. Each axis record lists original path/segment indices and exact scope
points. For a mixed edge, only the suffix after the verified vertical segment
is selected. The bend is an attribute limit, not a new physical node. Native
coverage runs on a private scope projection; public graphs stay immutable.

Run `pipeline.py validate-named-floor-segments --mapping-run ...` for independent
native replay. A valid source correspondence remains pending/exit 2 for
segment-aware DN/metric fusion, other interfaces and HIL. Never send these
partial mixed-edge records to a whole-edge attribute writer or propagate the
vertical DN across the bend. Keep graphic circle radius and unshown connector
length unknown. The exact-touching geometry/XY evidence is not itself proof
of cross-view identity.

Run `test_match_named_riser_floor_segments.py`,
`test_named_floor_segment_mapping_gate.py`, inherited naming, display-leg,
source-T/XYZ, circle, native branch, exact-chunk, crossing and metric tests.
SH16 10/11 third-floor CHWS1/CHWR1 and CRAH-4#-3-1 are a scoped source case;
they do not cover every floor or named riser.

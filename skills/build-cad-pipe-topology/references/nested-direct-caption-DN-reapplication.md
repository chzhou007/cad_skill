# 单一原生嵌套管线复用直接标注读取器

重复块模板不能唯一归属标注时，不代表原CAD缺少管径。先在完整WCS原生管线竞争集合上重新执行已有直接管段标注读取器；不要为套用旧块名、子句柄模板而降低四个独立对照的门槛。

`native_nested_direct_caption_DN.py` 建立私有、可逆的读取投影：包含全部当前图引用INSERT中的管道LINE和模型空间管道LINE，并保留原根块、子句柄、变换后XYZ、图层及原文字身份。所有标注及F引线竞争仍参与读取。中性图层0的嵌套LINE另外保留，并按原直接读取器的半字高竞争距离阻断，不能因没有供回水图层而忽略。

- 原有两度平行角、两倍字高范围、半字高竞争间距和原生TEXT变换检查不变。管径数值、设备编号和最近块不用于选择管线。
- 用原有源候选和`axis_local_DN_segment_domains.locate`核对唯一当前边、源Z以及原始竖段。旧值不被覆盖；不把局部管径写成整边值。
- 复用原有两臂弯头及成对省略符源校验，将新种子用于同一实际管路的剩余竖段。新增管径、F引线、重复源线、真实T或源路径不明仍阻断。本入口不新增连接。
- 图示长度、水平最终管径／长度、物理长度、元件和人工验收均不在本入口赋值。11图水平标注作竖向管径继承种子时仍不替代平面图最终水平属性。

正式入口：`pipeline.py reconstruct-nested-direct-axis-DN --manifest INPUT.json --output NEW`；独立重读：`pipeline.py validate-nested-direct-axis-DN --native-run NEW`。固定实际已发布的竖段父结果、原图、路由、查看器上下文和完整待解决集合。

回归覆盖完整模型空间／嵌套竞争、图层0近邻、旋转镜像、源Z、重复当前归属、F优先、冲突标注、真实T和弯头后继承。源图通过、查看器采用、实际导出、人工验收分别记录。

# 已知直连管段旁的独立锚定主管链

当原图与两图拓扑均有一条已确认直连路径，同时还有一条由未对应 T 节点组成的主管链，完整图中有环是正常现象。不能删除已知路径，再把删边后的最短路称为唯一对应；也不能因为存在这个已知环就永久放弃整条剩余主管链。

运行 `reconstruct-complementary-anchor-chains --manifest … --output …`，然后用 `validate-complementary-anchor-chains --batch-run …` 独立复算。

## 适用条件

- 完整当前 provider 必须在其原冻结运行环境中回放，普通节点锚点与成员节点命名空间分开。
- 供、回水分别搜索。两端是已经独立对应的同系统物理 T；未知内部节点均为同系统三向节点。保留完整源图、已知直连路径和原有对应。
- 每端锚点组合下两图各只有一条未对应的简单内部链；节点和分段数相等。按已知端点定向后的图同构确定内部 T 与管段，不使用坐标排序、最近设备、管径或长度比例配对。
- 已知直连路径本身必须在旧 provider 中有独立的一对一普通图对应。重复路径、额外分支、旧 writer 或内部节点数不同，均保持待处理。
- 所有 T 重新读取原生三向证据，所有可见源路径必须由唯一原生 LINE 覆盖。当前两臂圆圈阅读图与原图在这些节点的完整局部邻接必须严格一致。源 LINE 存在复合叠管风险时，返回已有成员重建规则。

## 继承炸开球阀

元件原先识别成功不代表跨图检查入口已经接入。`inherited_exploded_ball_profiles.py` 复用 `legacy_v17/build_edges.py` 中原有 HATCH＋两半 ELLIPSE＋三条 LINE 的几何识别内核；全模型范围只用于候选发现。选中实例还须满足完整六图元、变换后 WCS、同 Z、两条有限法兰线与唯一原生管线及图边接触。中心附近或相同数量不足以证明归属。不修改原实例或生成新元件。

平面归属必须调用平面源图的有限路径归属入口；不能套用轴测图限定的 `connection_mode` 白名单。原图有完整阀体但旧库存未登记时，先输出独立阅读库存，以源句柄建立稳定元件ID，保留全部旧行和原拓扑图。对08–10完整已知炸开球阀群批量检查，不限于本轮选中的边。选中源元件无旧归属记录时，检查必须明确失败，不能静默返回空 profile。

补齐已知源实例之后，元件记录仍不一致时才保留拓扑对应和双侧源记录，标记 `source_detail_difference`，阻止本入口采用属性。不能为了凑齐两图而删除阀门，也不能将炸开图元未接入误报给专家。SH16三层本轮原CAD对照已经证明：主管上的36个平面球阀确实存在，旧204行库存未纳入这些实例；“0对36”不能解释成画法详略差异。

## 输出与边界

输出独立的源证据、provider 和水平属性 frontier。只增加已证明的主管对应和内部普通 T 锚点；不配对旁支的未命名设备或外部接口。新锚点可供下一轮批量搜索使用，但不能循环证明本轮锚点。

连接对应、管径、物理长度、元件逐一对应和人工验收分别记录。本入口不填物理值；水平属性仍用平面图原生读数规则，全部竖向区间仍用轴测图。实际当前计数从 records/frontier 重新计算，旧阶段计数保留为历史。

正例：SH16 三层供、回水各 10 段链与独立直连旁路。反例：二层内部支路/节点数量不同、普通正交穿越、同井近邻、复合载体、已有 provider、错误 Z、缺失阀体图元与重复原生管线。

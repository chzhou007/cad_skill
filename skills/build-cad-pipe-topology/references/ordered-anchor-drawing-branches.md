# Drawn branches from source-proved main junctions

Use `ordered_anchor_branch_paths.py` after the original ordered-main owner has
independently fixed both ends, witnessed both native corridors and matched all
internal main Ts. The branch expansion cannot seed its own parent proof. Read
every new anchor and unused off-main route as one batch; do not infer equipment
from adjacent labels or assign shared marker quantity to unobserved ports.

At each proved main T, exactly two incident main arms and one same-service branch
must exist. Trace only a unique same-floor route through degree-two subdivisions.
Reject a second junction, equipment, cycle, parallel writer or competing branch.
Replay plan LINE coverage, the retained expert non-node boundary and all existing
axis marker ports/physical source segments. A new sidecar maps drawn branch
context; it does not connect remote systems or create a real port/equipment.

`native_drawing_marker_ports.py` reuses the native capped/external-port geometry
contract without inventing a caption, destination or cap role. Only existing
`standalone_omission_to_first_tee` source interfaces qualify. Each original port
must own one uniquely source-witnessed typed pipe endpoint on the native marker;
the complete marker inventory must have no extra/missing pipe contacts. Its
centre spans remain display-only and never join supply and return.

An edge ending with a typed `boundary_id` and `node_id:null` is a valid non-node
drawing boundary. Keep it as such. The old node-only `selected_snapshot` does not
handle these edges; the boundary-aware snapshot retains edges, real nodes and
typed boundary evidence, without creating substitute nodes. The existing expert
two-bar boundary tolerance (.6 drawing units of glyph placement rounding) is
retained only in that source role. The stricter capped-caption reader remains
unchanged: a failed cap interpretation must not broaden its contact rule or
turn a drawing boundary into a physical capped port. Native Z may be auxiliary;
retain it as evidence and do not use it as elevation.

Reuse `native_plan_projection_lengths` with the source service and independently
corroborated plan units. Count only native drawn pipe pieces. Circle radii,
marker-centre spans, unshown connectors, local vertical extents and complete axis
installed lengths stay separate/unknown. Preserve original component owners.
Missing implementation fields are errors, not semantic pending/HIL rows.

Local DN may be retained from the exact full-plan DN receipt used by the qualified
axis composition, with its original owner, implementation, output, manifest,
current plan/source hashes and exact selected scope paths checked. Do not swap
in a similarly named newer DN result. State this as qualified local-DN retention,
not a fresh whole-plan DN rebuild. Mapping must be independent of DN. Mixed or
conflicting DN stays local/unknown and never becomes a whole-axis scalar.

The versioned viewer owner `refresh_ordered_branch_attributes.py` preserves old
contexts, re-derives the prior ordered-main values from the source proof freshly
replayed by the branch owner, and retains the separately source-bound member
context. Expose new local DN/XY columns and explicit unknown whole-axis values;
all old effective CSV values stay exact. Use a new dataset identity and retain
historical annotations. Technical source validation is not human acceptance.

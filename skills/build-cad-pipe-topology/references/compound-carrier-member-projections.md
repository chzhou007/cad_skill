# Member topology before scalar DN inheritance on compound plan carriers

A label such as `DN300(3.600)/DN200(3.000)` belongs to two declarations. A
single native LINE can carry both projections. A T-inherited scalar on its
split children is insufficient evidence of a physical member, even when that
scalar was positive in a previous release. Preserve the old observation as
superseded evidence; do not retain it as the current whole-pipe value.

`compound_carrier_members.carrier_risks` carries the ambiguity along the exact
native LINE to all represented child segments, including reversed paths. A
nearby different LINE is not blocked or assigned by that lineage rule. Multiple
native carriers in a drawing edge remain separate barriers; they do not abort
unrelated source-qualified intervals.

`native_paired_end_labels.collect` reads native TEXT end columns as paired
geometry. Two same-profile captions outside parallel pipe ends need a unique
one-to-one, order-preserving two-service association on the same annotation
side. It considers all modelspace pipe LINEs, retains competing candidates,
and does not use DN or level values to choose pipes. Unsupported transforms,
interior captions and competing columns retain their original readers or
remain unresolved. This is distinct from an explicit F leader.

Resolve a member only on an existing independently checked main correspondence:
replay original mapping/topology owners, both view snapshots, unique native
LINE coverage and both endpoint Ts. For this wave-branch family require two
independent equipment/branch anchors on the plan carrier. Compare the axis
caption's literal level token with the plan declaration tokens; exactly one
consistent declaration per text must result. Select DN from those plan
declarations, then use axis DN only as a cross-check. Equal DN alone cannot
select a member. Tokens do not establish physical elevation, units or datum.

Use `rebuild_compound_member_projections.py --manifest MANIFEST --output NEW`,
then `pipeline.py validate-compound-member-projections --member-run NEW`.
The manifest pins the original source/graph/mapping/current-parent inputs,
floor, current junction providers and native unit policy. The new member graph
contains only checked member main intervals and their original logical
equipment branches. It retains drawing IDs as aliases, separates member Ts,
and keeps unsupported members and global topology completeness pending. Do
not duplicate all old contacts onto both pipes or create physical equipment.

Measure T-to-T run centreline with the original plan unit/coverage reader;
source point order is not flow direction. The run includes inline assembly
extents. Projected component-to-member allocation, net cut length, unshown
connectors and installed whole-edge length remain unknown. Original axis
components keep their existing ownership. A local member graph is not yet a
complete calculation graph.

Before publishing a correction, replay its receipt, compare every old effective
attribute, explicitly list superseded scalar values, keep unrelated values and
annotations, invalidate semantic HIL, and inspect wide/local native Pairs plus
actual browser and CSV. Development screens with mocked ancestry are not
qualified artifacts and cannot replace this gate.

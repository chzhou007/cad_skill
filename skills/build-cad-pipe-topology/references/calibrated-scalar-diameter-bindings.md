Use after the local plan topology and selected source paths are independently supported. This extends the strict scalar binding entry for close parallel pipes; it does not replace F leaders or introduce a global text-side convention.

`calibrated_direct_dn_evidence.py` first replays controls through the unchanged strict scalar extractor. Require at least four distinct native source LINE controls with the exact target TEXT profile (style/font, size, width, layer and supported transform), supply and return evidence, and two independent annotation directions. Targets cannot be controls. All matching controls must agree on signed text-normal side. Either sign is allowed when independently learned.

Search every parallel native modelspace pipe, including pipes absent from the graph. Retain only candidates within the old two-height envelope and on the learned side; require exactly one native LINE, its correct service and one current source-backed graph segment. Competing same-side pipes, duplicate LINEs, changed profiles, mirrored/unsupported TEXT, conflicting DN, unparsed nearby notes and F/other leaders remain unresolved. Preserve parenthesized text without converting it to length. Output is a local native binding, not a whole-edge physical value or human acceptance.

It supplies those directly verified seeds to the existing `plan_pipe_diameter_scopes.group_evidence`; the default old entry remains unchanged. Reuse genuine T/native through-main checks, finite source frontiers, branch explicit overrides and separately audited crossover paths.

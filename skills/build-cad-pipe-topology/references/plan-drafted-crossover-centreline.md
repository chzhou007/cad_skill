# 平面交叉断画的完整水平中心线投影

平面主管缺完整长度时，区分三种情形：已证明的不同系统交叉断画、长管波浪省略、软接或绘图接口内部。只有第一类可使用 `reconstruct-plan-crossover-centrelines` 和独立 `validate-plan-crossover-centrelines` 补完整**平面XY中心线投影**。这不是安装长度、净下料长度，也不声称跨越处的实际标高或实体斜长已知。

入口先复算当前完整成员对应批次，在已对应且缺长度的整个水平范围筛查。保留原管径、原完整长度、未对应范围及其他专用owner。比例须由原生平面单位、两方向尺寸与楼层范围印证；实际量测仍逐段引用原生LINE。不能用附近尺寸直接给管道赋值，轴测水平尺寸不参与量测。

断画必须经原 `path_evidence`／`correct_plan_crossover_lengths` 独立重读：两个同系统原生LINE端点对向共线，唯一异系统管线穿过两者之间，交点处两系统没有共用节点，全部路径由这些交叉证据构成一条链。复用原有精确相接路径归一化；所有原始路径、未知physical length及标高、原始断口记录保留。重复源线只能复用完整成员cohort已证明的私有读图投影，不能按相近或等值去重。端点须到达两端真实T，不能把圆圈半径、立管图形或未画接管纳入。

两个局部图和当前对应的设备、元件、系统、端点及原图哈希都需复核。新结果独立列出已画管段XY和交叉断画XY，前端显示“完整水平中心线投影”，同时保留“安装长度未知”。语义变化使相关人工确认失效，旧批注保留。

SH16保护反例：二层E0168／E0181虽然交叉断画可复读，但支路止于连接圈外缘，不能获得完整T到T投影；三层E0409／E0429两端均有原生T及完整成员对应，可分别得到6.250／7.300米的完整水平中心线投影。波浪省略、软接内部、普通未证实断口和同系统连接不套用此规则。

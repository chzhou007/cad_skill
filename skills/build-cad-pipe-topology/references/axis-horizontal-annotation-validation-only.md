# 轴测水平标注只校验；无明确长度的竖段留空

专家最新答复撤回了“用11图水平管括号值反推竖段长度”的候选路线。此前0.600米、5.000米只是未采用研究候选，不能因数值看起来合理而写入管长，也不再等待对该推算方法的单位确认。

- 水平主管的长度优先取正确匹配的08–10平面原管路。轴测水平表达的标注只作一致性校验，不能作为物理长度来源。
- 不将11图水平管标注的3.200、2.600等值自动传播到未知竖段端点，再相减得到长度；“哪些管属于该标注”尚未证明时尤其不能采用。
- 竖段仅采用11图中明确归属于该实际竖段的长度证据。没有该证据就留空，不能用图示Y距离、通用层高或水平标注替代，不填零。
- 管径与长度独立验收。直接标在竖管上的DN及经源证据证明的继承可以继续，不能因此声称长度完成。
- 当前优先级是已有平面主管路径的完整长度与属性接入，然后处理剩余跨图路径。研究候选保留为历史，按已否定采用的状态标识；原答复不重问。

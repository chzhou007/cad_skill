# 消费元件表达差异答复后，复用原管路长度规则

`reviewed_source_detail_metrics.py` 支持专家明确确认的“平面省略，实物按轴测两阀”。通过已接收答复的题目、原始Pair、源范围及元件数量重新绑定，只解除所选一对一主管范围内的元件表达差异限制。

正式入口：`pipeline.py reconstruct-reviewed-source-detail-metrics --manifest MANIFEST --output NEW`；独立复算：`pipeline.py validate-reviewed-source-detail-metrics --verify-output NEW`。

原完整父阶段产物保持为有固定版本的继承证据；本入口重新运行原第三臂发现器、两端三通、完整LINE路径、球阀原生形状／WCS法兰／实例归属及平面单位、端点范围和中心线长度读取器。记录明确区分继承父产物与当前局部原生复算，不冒称重新运行整个父流水线。

- 原管径冲突继续保留，管径不参与映射或长度选择。元件数量答复不能解决250／300分区，也不能补竖段长度。
- 两图所有原始元件均保留，轴测实物两阀作为确认结论记录；不制造平面第二只阀的位置，不跨图合并元件。
- 断口、波浪省略、软接内长和同层竖直段仍由各自原规则处理，不能因为答复而补长。完整平面中心线与安装长度、净下料长度分开。
- 查看器扩展既有中心线上下文；原记录及来源保留，新范围另有答复／Pair／原生证明绑定。实际供回水CSV、完整旧值守恒和页面验证完成后才计入发布。

# 环内立管角色锚点与不等长支路链

当已确认环路入口后仍有内部对应缺口，先复用当前完整 provider inventory 和原生环路证据，运行 `pipeline.py reconstruct-typed-cycle-riser-batch --manifest MANIFEST --output NEW_RUN`，再以 `validate-typed-cycle-riser-batch --riser-run NEW_RUN` 独立回放。

只处理至少两个已确认入口约束的同楼层、同系统简单环。平面端候选必须是已有 `out_of_plane_riser` 接口，且在环外只有一条接管；轴测候选须为环外唯一的同层立管三通，其另外两臂分别通向上下楼层，原生方向读取均有竖直区间。同层竖直线、普通末端接口、仅靠楼层字段或颜色相近均不足以满足此角色。两侧角色各唯一，才提出环上接入三通及限定立管接口对应；普通节点与立管接口保持独立命名空间。

对应前独立重放原有完整提供者，检查原图哈希、平面立管原生圆及系统图层、两侧接入三通和轴测立管三通的原生三臂。直接区间还须两侧各唯一、元件分布一致、所有图示路径片段具有唯一原生 LINE 覆盖。源图歧义保留，不以截图或节点序号代选。

三个以上已知环上锚点可以唯一限定它们之间的环弧。保留有序源路径用于描述范围；有序范围本身不证明内部节点身份。两图内部支路数量不同，记录整体路径边界、各自分支数及源证据，明确逐节点、逐边对应未完成。不得把整体路径候选直接写成每条边的管径或长度，也不得按顺序、屏幕位置、管径或长度消除多出的支路。相同支路数量也不是身份充分证据。

SH16 回归覆盖 08–10 当前全量环路候选。09 的供回水环各有一个立管角色，11 分别具有上下楼层的连续立管；环内两图仍各差一个末端支路。唯一立管接入是正例，13／14 末端支路差异必须保留。后续复用平面属性读取；轴测所有竖直部分（含同层升降）继续从 11 取值，未知不填零。源回证、属性读取、发布、原图对照和 HIL 分别验收。

测试覆盖独立入口、唯一／重复角色、异系统、同层升降反例、未知方向、断口、额外三臂、镜像与管径扰动、原生圆图层／坐标／OCS、以及整体路径不能提升成逐边属性的流水线保护。

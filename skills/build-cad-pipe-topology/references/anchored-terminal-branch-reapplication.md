# 已对应主管锚点的旁支规则复用

主管两臂已有独立对应后，应整批检查各内部T剩余的一臂。复用原 `ordered_anchor_branch_paths.outward`、原生T、源路径和绘图边界判读器；不重新逐个猜测设备名，也不按末端排列顺序绑定。主管本轮新增锚点只能用于后续旁支，旁支不能反过来证明自己的主管父结果。

`reconstruct-anchored-terminal-branches --manifest … --output …` 回放冻结发布版父结果及其实际查看器采用，然后运行整组旁支。`validate-anchored-terminal-branches --batch-run …` 独立重算。构建完成不宣称独立验证、查看器采用或人工验收通过。

## 原有规则与临时读取接口

平面中已保留为 `out_of_plane_interface` 的原生80单位圆和四条完整符号线，使用原 `cad_ceiling_native_rules.match_out_of_plane_symbol` 核验。只有同楼层、同系统、唯一度一端点能在临时阅读副本中适配为通用绘图接口类型，以调用原向外路径规则。原图、原节点和接口身份保持，不产生物理设备、实物端口或远端设备归属。

轴测侧复用原 `native_drawing_marker_ports.collect`，完整核验独立的源线、标记和两系统分开的绘图端口。它因端点未接触标记或源路径不唯一而拒绝时，不扩大公差，也不借邻近端口绕过。两图都只在明确的第三臂上建立绘图范围对应。

平面供回水跨越的断画必须调用原 `source_checked_plan_path_coverage.audit`：复查历史圆周支路和每个异系统穿越，再用原 `native_plan_projection_lengths.lengths` 读取已绘片段。不能用仅验证可见片段的批量覆盖结果，冒充断口本身的连接或完整物理长度证明。缺口和未画接管不填零。

## 批量与失效边界

主管两侧对应必须已进入完整当前provider，并且两条主管臂分别有独立原生证据。保留任何已有轴测或平面writer及成员命名空间。所有当前新增锚点的第三臂都列入结果或具体pending原因；未识别源端点不能删除。源图、原边、源路径或父对应改变后，旁支结果失效并重算。

只有平面局部管径和已绘XY路径可以成为后续属性输入。混合边不因此获得整边管径或完整长度；所有竖向片段仍由11号图本体提供证据。源对照、实际页面和导出通过之前，正式对应及完成数不增加。

SH16正例：三层独立主管链的新T锚点与完整VIF圆形符号及独立轴测标记。保护反例：未解决源断端、少一个符号图元、不同系统、普通交叉、额外标记端口、端点不接触符号、源线不唯一、已有writer及两个普通锚点合并。二层13组平面接口与14组轴测接口的数量差异不能靠此规则强配。

## 查看器与目录采用

`refresh_anchored_terminal_branches.py` 接入原查看器组合读取器，追加8列旁支局部证据，原256列逐格不变。仅在实际读取器采用后才登记新的绘图范围对应，普通节点锚点、成员域、元件及竖管域保持；混合边不因此计为纯水平完成。检查新HIL语义身份、大范围原图与局部Pair、实际下载CSV后，再发布目录。

## 主管细分后的跨管断口读取

已发生有来源约束的主管细分时，旧路径包装器可能仍要求旧主边身份。`current_plan_crossover_path_reapplication.py` 复用当前T读取器的 `current_main_lineage`，要求同一源图／图版本、完整同系统三臂、唯一圆周支路、原父版本哈希和实际当前主臂身份，然后调用未修改的原 `branch_coverage` 与原量长内核。没有这种已证明谱系时仍走旧完整路径入口。它既不改历史图和收据，也不扩大断口或连接公差。SH16 E0089／轴测E0451为正例；错误哈希、缺臂、错误支路和缺少父版本的谱系为阻断反例。

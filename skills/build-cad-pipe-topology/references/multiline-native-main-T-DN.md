# 原主管分段与真实T的管径继承

当已证明的同系统主管因转弯或T细分而由多条原生LINE组成，使用
`reconstruct-multiline-main-T-DN` 与 `validate-multiline-main-T-DN`。
整批处理当前未知竖段，复用原直接标注、同Z两臂弯头、真实三通和
整条支路的管径／F屏障；不把同一LINE当作主管连续性的唯一形式。

源归属取自原逐段 `native_witnesses`。边的 `source_insert_handle`
可能指向省略符或接口图形，不能据此断言所有管线都在该块内部。
每段仍须唯一源覆盖；混合源命名空间未证明时留待核。

从目标支路的真实T出发，两个反向主管臂分别寻找独立原标注。
主边内部只通过原同Z两臂弯头，跨节点只走经源图重算的三通直通臂。
不拐进中途支路借其管径，不越过未证明省略／软接，不按最近标注强选。
两侧候选冲突时保持未知。整个目标支路（含其他绘图路径）上的新管径、
复合管径和F标注仍阻断；供回水及普通交叉保持独立。

必须把目标T两侧完整原生主管LINE也放入标注屏障检查。另一侧的标注即使
尚未获得唯一直接归属，仍可能界定变径；不能因为已走通的一侧有种子就忽略它。

只补原竖段管径，不扩大整边管径或推定长度。全部竖段取11图，水平最终
属性取平面图。轴测水平标注及括号值只校验；未知竖长不从层高或坐标推算。
共享测试包含主管转弯、多T直通、支路种子反例、变径屏障、错误源Z、重复线、
省略符句柄与实际LINE归属，以及冲突候选。源级通过后仍需查看器采用与导出核对。

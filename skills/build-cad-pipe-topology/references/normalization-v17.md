# Shared normalization and source coverage — v1.7.0

Run normalization before equipment port binding, junction detection and logical edge tracing in every drawing family. Use `topology_normalization.py` and `straight_crossovers.py`; current family entry points are `build_schematic.py`, `build_ceiling_family.py`, `build_outdoor_family.py` and `build_isometric_v17.py`. Keep source layers, symbol libraries and lengths in the project configuration. The SH16 profile (gap limit 500, elbow length 10, ratio .1, angle 20 degrees) is calibrated to these native drawing units, not a universal default.

An elbow overshoot is removable only if the tiny end is dangling, unprotected by equipment ports, has no other attachment, meets a second line at that line's endpoint, and leaves two real directions after clipping. Do not delete T nodes based on degree alone. Preserve true short branches, source-supported three-ray attachments and device ports. Native source files remain immutable.

A straight crossover needs opposed collinear tails, a unique same-system or same-known-source-group pairing, an empty gap and independent crossed-pipe evidence. Evidence may be a continuous pipe or two opposing collinear pipe pieces. A genuine branch at a gap endpoint remains connected; only the independent interior crossing is protected. Reject ordinary gaps, valve/equipment/display gaps, conflicting groups and competing matches. Unknown ACI hydraulic service remains unknown. Curved bridge symbols mean independent pipes with unknown relative elevation.

Discover candidates independently from the final graph and write a source-coordinate ledger: handles, endpoints, witnesses, rule, status (applied / display_excluded / pending), reason and resulting logical edge IDs. A bridge in an intermediate geometry list is not enough: prove that its entire span occurs in a final edge. Missing endpoint semantics may use an explicit review-required virtual boundary; never describe that boundary as a verified physical equipment port. Keep unsupported nested geometry pending rather than forcing it onto a nearby edge.

For merges, concatenate full source paths, retain component instance identity, ownership, related edge IDs, ports and source handles. Prefer the equipment branch ID; emit `id_mapping.json`, keep unaffected IDs stable and audit per-instance conservation. The SH16 new baseline is 423 nodes / 575 edges / 1560 components, with T053–T056 and E0093/E0095/E0097/E0098 retired. The historical 427/579 fixture is retained as history. T173's pre-existing degree-four exception remains pending.

Gate on independent source-gap coverage, final junction directions/adjacency, edge endpoints, per-instance conservation, native display fidelity and portable Pair consistency. Source ambiguity may remain pending; a known implementation defect blocks delivery. Technical gates never create human error groups, confirm a review or close an expert issue. Run the normalization positive and negative tests plus all existing source/component tests. Report count and connectivity changes by task, not just matching totals.

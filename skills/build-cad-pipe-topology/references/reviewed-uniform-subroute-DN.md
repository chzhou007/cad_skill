# 同范围中剥离已确认前缀后的统一管径

两视图内部支路数不同，不必然阻断统一管径传递。前提是同范围对应已独立回证，两端锚点、源线和局部拓扑成立；并且另有独立映射的上部成员前缀。把这段已确认前缀从两个**原有有序路径**中精确剥离，不能在剩余未匹配边里挑最短路径。

`reconstruct-reviewed-uniform-subroute-DN --manifest M --output NEW` 重新执行范围、成员、管径源域及锚点校核；随后执行 `validate-reviewed-uniform-subroute-DN --verify-output NEW`。仅拟合节点数或同DN不构成匹配证据。来源继续是平面图；轴测标注只参与一致性检查。

SH16二层圆12E8F的DN300接入段已独立对应到11图E0187，并有成员、元件归属及三通锚点证据。该已确认前缀之后是DN200成员；其他平面区段须全部经原生T与标注读取器证明同为DN200。内部节点身份和长度仍不分配。13条纯水平边和两条混合边中的5个水平子段可进入该管径范围；混合边中的3个竖段仍由11图自身处理，不给混合边赋整边管径。供水范围有原有局部源证据缺口时仍保持held。

旧校核器对完整LINE查找标注，可能把前缀已归属的DN300标注误用于圆后DN200成员。例如B854在源LINE B66C上，投影足点严格位于圆12E8F之前的已回证前缀。`qualified_member_caption_scope` 先执行原前缀标注校核，再检验原TEXT、原生LINE、同系统、Z、严格的投影范围和目标路径无重合；只有这些条件全部成立，才在私有读取视图中排除该已归属前缀标注，再运行原目标校核器。

这不是放宽管径规则。边界处、目标内、其他Z、未知归属、F标注及新的不同管径仍阻断。源图不删除标注，不改变原阈值；复合声明的上下成员仍由原对应所有者处理。当前已知管径不得覆盖，全部缺失长度保持未知。源级管径通过不等于查看器已经采用，也不提升长度完成数。

完整旧管径／量长父产物作为字节及实现哈希固定的继承证据保留。本入口重新执行完整当前范围所有者、完整原生成员及来源所有者；以原生范围的独立边界、成员角色、几何和原标注校核重新证明当前选定前缀，不把旧产物里的“已通过”当作新证明。这里不宣称重新运行所有历史量长流水线；其他历史完整入口的回归状态单独记录，不因本局部通过而关闭。

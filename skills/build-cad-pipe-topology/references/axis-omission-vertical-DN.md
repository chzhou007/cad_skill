# 轴测省略路径之间的竖向管径继承

适用：同一设备支路已经在原生块重建中证明省略符两侧相连，一侧有独立读取的管径，另一侧竖直段仍未知。单纯同一 edge ID 不足以继承。

使用 `pipeline.py reconstruct-axis-omission-vertical-DN --manifest <固定输入> --output <新目录>`，再用 `validate-axis-omission-vertical-DN --dn-run <目录>` 独立重读源图。

- 对全部未知竖直域筛选，不硬编码边号、设备号或 DN80。
- 复用原有 repeated-layout 管径归属的原始候选分组。把所有目标合成一组会移除原本独立的校准样本；不得靠降低四个独立实例的门槛补救。
- 重新读取原生 INSERT 中的两枚六顶点省略符；重放原有源坐标、端点快照和两侧接触，要求同系统、同源 Z、唯一端点。供回水、普通交叉或任意近接点不因此连通。
- 省略符到标注与目标段之间复用原有两臂弯头连续性检查；额外支路、重复源线或变径标注阻断继承。
- 距离检查可能把邻近的另一系统标注误认为变径。只有本轮重新执行原有管径归属读取、证明该文字唯一属于另一系统源线，才从本继承域排除；同系统、未知归属、F 形标注继续保留阻断。
- 只新增目标竖直段的管径与继承证据。省略段长度、软接长度、实体设备端口仍未知；水平段继续取平面图；本规则不跨越软接或物理 T。

输出保留旧管径证明、源文件哈希、继承链、全部剩余未解决域。技术源图回证与查看器采用分开：脚本产生结果不等于当前页面已显示，也不继承人工验收。

回归：`test_axis_omission_vertical_DN.py` 覆盖镜像、移动符号、额外符号、旧端点快照、系统变化和邻近另一系统标注；同系统变径与 F 引线为保护反例。原有省略符重建及单路径竖直继承测试必须同时通过。

# 不同内部支路数量的范围量长

主图与轴测已由独立两端锚点及原生路径证明同一范围时，可在不确定内部节点对应的情况下读取平面的源LINE片段长度。不能把“13组／14组”视为必须逐个配对，也不能把总长按边数分摊。

使用 `reconstruct-reviewed-expression-metrics --manifest M --output NEW`，随后用 `validate-reviewed-expression-metrics --verify-output NEW` 独立重放。入口先重新执行既有范围对应所有者；任一侧存在局部源图缺口的范围保持held，不采用专家的同范围答复覆盖局部错误。

旧量长配置的窗口用于限定单位校验和读取范围，窗口本身不是建筑边界。例如二层旧右界2390000，已由原生LINE回证的主管到2390122.639。对已经通过两侧源图检查的当前范围，可在私有量长视图中只扩展至该范围的源线端点包络；原图、全局配置和单位判定不变。原始楼层标题、两方向DIMENSION、无文本覆盖、比例因子和毫米单位仍须全部通过。不得用扩大窗口把详图或另一楼层当作平面量长域。

每个源路径片段继续调用原 `native_plan_projection_lengths.lengths`，保留原路径索引、源LINE、源坐标和单位证据。多段路径可分别量已画部分，但中间缺口不补直线、不记零、不算圈半径。分离的路径明确标识未知接管，不能宣称完整实体长度。

输出是**范围级已画平面LINE片段之和**，不是每条轴测边的长度、整段安装长度、净裁长或竖管长度。内部身份、逐边分配及管径保持未知；复杂300／200声明继续由独立管径所有者处理，不由量长功能挑选。整组对应、范围量测、逐边属性三个状态分别报告。此类结果尚需查看器接入才能成为11图在线属性。

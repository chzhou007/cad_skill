# Current context branches and named floor approaches

Use `current_remaining_floor_plan_scopes.py --policy POLICY --output OUTPUT`
after the current paired DN/XY owner has replayed. Its input policy pins that
complete parent, historical named paths and policies, the independently checked
axis riser scope and the retained full axis presentation.

Rebuild each context-only equipment service from the complete current
inventory and native paired paths. Context-only prevented earlier duplicate
publication; it does not mean an unconnected device. Read its current plan DN
from the freshly recomputed paired groups and remeasure only native plan XY.

For named approaches, independently replay the axis through-riser owner,
native TEXT/underline/leader/circle names in both current views and the
equipment-service anchor. Reuse `correspond`, native through/branch contracts,
`named_annotation_domain`, DN inheritance and metric helpers. A named riser
DN450 annotation cannot seed a horizontal approach DN300. Graphic circle radii
and unshown connectors remain excluded from physical lengths.

Route DN ownership by actual source representation. Repeated nested-instance
calibration is not an appropriate reader for a modelspace LINE. For the latter,
reuse native path coverage and the frozen selected-segment DN candidate kernel.
`partial_segment_evidence` preserves original indices and every unverified
remaining span; only a selected uniquely witnessed modelspace segment can enter
that reader. Its result is still a local geometric annotation candidate, not
semantic ownership of a whole edge, an inferred reducer, equal plan/axis
extents or inter-floor vertical evidence. Do not hide a plan DN300 / local axis
DN65 difference by source priority or a newly invented transition.

`pipeline.py validate-current-remaining-plan-scopes --scope-run OUTPUT`
independently reconstructs all source evidence. Keep full-parent adoption,
source comparison, publication, whole-network correctness and HIL separate.
Historical IDs, raw annotations and answers remain versioned.

Tests: `test_current_remaining_floor_plan_scopes.py`,
`test_current_remaining_plan_scope_gate.py`, and the named, DN inheritance,
native-segment and metric suites.

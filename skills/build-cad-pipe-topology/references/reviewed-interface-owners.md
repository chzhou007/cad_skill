which ordered supply/return interface groups belong to existing native equipment.

source-calibrated ownership or infer an owner from a label, body rectangle or
nearest distance. A partial reply about surplus drawing circles is insufficient.

and actual Pair bytes. Preserve original question IDs and image/source hashes.

do not let a new configuration reverse them or select an arbitrary nearby device.

two explicit paired-owner confirmation choices represented in its tests.

# 历史自动排气阀显示支腿：拓扑与属性入口一致

这是既有规则的继承接入，不是本轮新发明的设备识别。旧 `legacy_v17/analyze_graph.py` 通过原生 `ATTDEF:WHAT=自动排气阀／自动放气阀`，把显示支腿回折到真正弯头；主拓扑和元件清单已采用该结果。如果属性读取直接使用原始 LINE，可能又数出第三条射线，把同一个弯头误判为待核 T。

使用 `reconstruct-inherited-air-vent-attributes --manifest <固定输入> --output <新目录>` 及 `validate-inherited-air-vent-attributes --attribute-run <目录>`。

- 重新执行原有短延伸、阀件支腿、排气阀归一化内核，保留原参数和源实体；不扩大1000绘图单位的原有显示支腿上限，不把该绘图长度当作物理长度。
- 对完整已折叠放气阀群，逐一复核语义锚点、同系统原生 LINE、当前弯头、标准元件实例及其唯一归属。当前图仍保留物理 T、显示段仍是活动边、放气阀端有另一根真实接管或源线重复时保持未解决。
- 生成私有属性源线视图。`remove` 只排除该显示支腿；`trim` 只裁去同一源 LINE 的显示尾端，并保留原始 XYZ、源句柄和折叠证据。源 CAD、主图、设备和元件不改。
- 通过私有依赖入口复用原有连续源线管径读取器，完整筛查当前剩余竖段；历史已发布记录仍需原样复现。没有新增管径也要记录真实结果，不能把“入口修复”写成数值覆盖提升。
- 端点标高读取必须使用同一归一化视图，先核对真实 T／两臂弯头，再绑定原生楼层标高。跨层两端括号值相同不等于零管长；同层高差也不能套层高。标高单位及括号参考基准未选定时，只输出源数值候选，不填写物理长度。

回归 `test_native_air_vent_attribute_items.py` 覆盖原有 trim/remove、镜像、真实端口延续、重复源线、活动边及元件归属保护；`test_axis_direct_endpoint_level_evidence.py` 验证同层偏移与跨层基准计算，以及未知单位、原图坐标和物理长度的界限。历史规则、组合入口、剩余整群和实际交付分别记录证据。

Use `inherited_wave_pair_continuity.py` when the current plan contains a paired long-pipe drawing break and real expert controls exist in an earlier plan. Replay both current ownership and control ownership entries first. The old `repair_calibrated_wave_omissions.py` remains unchanged; do not insert a false expert-control root into another drawing to make it run.

```
python inherited_wave_pair_continuity.py --source PLAN.dxf --graph GRAPH.json --devices CSV --control-source CONTROL.dxf --control-graph CONTROL.json --control-confirmation CONFIRMATION.json --control-issue ISSUE.json --control-image PHOTO.jpg --policy POLICY.json --output RUN
```

The policy pins every input SHA256, `block_name`, `control_block_name`, `block_fingerprint` and explicit `pairs` (`nodes`, `wave_handles`, `retained_edge`). Require actual original expert issue/source binding and the exact later drawing-convention statement/photo/scope. Recheck each control's native separate paths, both endpoint pipe witnesses and transformed wave geometry; controls remain source evidence, not whole-graph acceptance.

The historical insertion-distance screen is a discovery aid. A wave can be slightly displaced from the real pipe endpoint. For SH16 10's west supply pair, that displacement is about 23.31 drawing units and exactly repeats the original expert-confirmed SH16 09 pair. Match the complete relative native geometry and actual pipe-end span against that control; never increase global snapping or insert a synthetic endpoint. Preserve XYZ and signed offsets. Rotation/reflection must reproduce the same pipe-relative geometry and bulges, and competing marks, different offsets, native Z changes, nonfacing endpoints, wrong floors/systems or unexplained native pipes in the gap fail.

Represent one evidenced same-system continuation as one edge with the two original drawing paths. Remove only the two nonphysical drawing terminals, conserve all components and outer port IDs, and retain an explicit old-to-current edge map. Keep an already split T-side child ID when it is the referenced current owner. Preserve every split-source field in hashed constituent snapshots; do not leave a single old interval descriptor pretending to describe the new combined edge. Unknown fields and active retired-ID references fail rather than being dropped or blindly redirected.

The wave adds no hydraulic component or special physical property. Drawing gap, circle radius and omitted physical pipe length are not measured lengths. The canonical CSV changes only component edge ownership. Mark dependent inventory, mapping, inheritance, fusion and HIL stale; retain prior annotations as history and rebuild those layers before publishing. The formal root stays pending/exit 2 for that adoption, whole source comparison and HIL.

Run the new native/control/reconstruction and gate cases plus existing wave, split-main, T, component conservation and endpoint suites. Verify exact preservation of all unrelated graph objects and source paths on the actual drawing. Do not apply paired continuity to unmatched single waves; their remote destinations still need separate evidence.

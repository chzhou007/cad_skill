# 显式答复接入平面圆圈省略连接

适用条件：当前拓扑已保留圆圈、同系统主管的两个子段和远端支路，但原生核验因该位置不在较早专家圈选范围内而保留待核；后来收到针对该圆圈、该支路和同一版本 Pair 的明确连接答复。旧问题的“相似位置”说明不能替代这份答复。

`received_projected_circle_authority.prepare` 重放原答复接收入口，核对归档的原始题目、浏览器快照、源 CAD、图版本、大图定位框和 Pair。只接受 manifest 明确绑定的问题、节点与肯定选项；拒绝更换节点、相同外观的其他位置、否定或含糊答复以及变化的图像。新答复作为单独来源保存，不改旧问题文件、不扩大旧圈选框。

沿用 `native_projected_circle_main_role.collect` 的全部原生规则：目标框中的同系统最左圆须唯一；圆落在原主管 LINE 上；两个主管子段相反且源 LINE 唯一；远端支路保留自己的实际 LINE、方向与端点；源实体、图层、系统和拓扑身份必须一致。普通正交、供回水交叉、竞争源线或框外位置仍失败。若新题不满足原规则，不放宽规则而冒充通过。

共享 `reader` 仅接替旧核验的“该连接不在明确专家范围内”这一项错误，不吞掉原生几何歧义。`collect` 输出旧主／支臂接口及新的答复证据，因此后续原管径继承核仍可复用；不补画第三根射线，不生成实际接管长度、标高、流向或新边。

## 正式范围重建

运行 `pipeline.py reconstruct-received-circle-expression-scopes --manifest M --output NEW`，复验用 `validate-received-circle-expression-scopes --verify-output NEW`。

M 固定原归一化双视图范围 manifest 和新答复授权 manifest。授权 manifest 固定接收回执、原页面根目录、问题 ID、节点 ID、肯定选项和原定位框索引。完整入口先重放原两视图的独立端点、原生路径、所有 T 和轴测原归一化，再重核已明确答复的平面圆圈。只移除该位置的旧范围限制；其他路径缺口、源线或 T 错误仍保留。

结果允许两图内部支路数不同，但不会因此配对内部设备、节点或边，不把范围总长分配给各边，也不直接赋予管径。竖段来源、缺失长度、历史批注和其他问题答复保持。

## SH16 使用边界

12F6D 使用已收到的同版本答复：支路 E0208 接入原主管 E0142／E0253；供回水独立，省略接管长度未知。11 图 T306 继续使用已重放的原始归一化证据。

整层管径入口仍须遵守当前局部图版本。较早整层 DN 的二层父图为设备归属更新前版本，不能把其图哈希改成当前图来直接重用。接入整层 DN 前须重放所属局部 owner、重新提取当前注释及路径，并保留既有分区、F 形、校准和已知值；本范围产物不能冒充完成这一步。原完整入口及其回执保持。

# Compose current named-prefix evidence over a complete axis parent

Use `adopt_current_named_prefix_evidence.py` after the native named-prefix
version bridge and complete known-junction-main parent independently replay.
This stage changes provenance, not correspondence, pipe values or geometry.

```
python adopt_current_named_prefix_evidence.py --policy POLICY.json --output NEW_RUN
python pipeline.py validate-current-named-prefix-evidence-fusion --fusion-run NEW_RUN
```

Policy pins the complete parent graph/component table and native bridge plus
receipt. Match the parent's original upper-floor scope/mapping hashes, current
wave graph, all four scope IDs, services, native DN lineage, XY pieces and
original axis segment limits. Keep approach values scoped beside the preserved
vertical segments. A prior complete horizontal main retains its original
values; the evidence bridge does not assign another whole-edge value.

Each selected edge receives `current_named_prefix_source_evidence`. The root
`sourceCurrentNamedUpperPrefixEvidence` binds those four records to the exact
complete parent and native proof. Removing only these owned fields must
restore every old graph field, node, component and annotation reference. Copy
the component CSV byte for byte. Do not fill unknown pipe or connector lengths.

The source-comparison dispatcher must process this newest root before retained
known-main and older roots. Independently replay the fusion, restore the exact
parent and preserve its complete errors/pending/history. Success remains
pending/exit2 for source comparison, viewer and HIL. Old manual acceptance is
not inherited.

Before publication, register the root in the viewer's native evidence ancestry,
retain all four per-edge proof objects through serialization, and expose their
current/historical source versions in properties and CSV. These are four
provenance records, not four additional mappings or plan values. Native replay,
complete-parent equality, actual properties/CSV/browser and manual visual
checks are separate publication requirements.

Run the fusion, source dispatcher and pipeline-route tests with the old upper
scope, current floor and known-main comparison tests in one complete isolated
skill tree. Mixed installed/candidate script paths can invalidate the tests'
real extractor hashes; fix the test layout rather than weakening those guards.

# 已知锚点约束下的环路入口匹配

当原有主管规则因存在环路而拒绝“唯一桥路径”时，先比较两图拓扑，使用 `reconstruct-anchored-cycle-gate-batch`，不要转为逐条截图匹配或选最短路线。

## 可确认的关系

1. 继承当前完整 provider inventory 的已验证普通节点对应。成员图保持独立命名空间。
2. 按楼层、供回水分开，在已知节点处分区；所有原始节点和边保留。未配对区域内识别简单环的双连通块，平行双边和带弦复杂块不套用本规则。
3. 对环上每个入口，沿环外管路追踪至首个已知节点，形成已知锚点集合。环至少具有两个独立锚点；两图环块及入口签名均唯一时，产生入口三通对应。
4. 重新核验原生 CAD 三臂证据。利用新入口加旧锚点批量找直接区间；两侧均只有一条直接边、原生 LINE 覆盖唯一、元件分布一致，才确认该区间对应。

两图环内支路数量可不同。入口对应不能自动确认环内其余三通的身份；数量差异必须保留并进入双视图差异队列。不得用节点顺序、屏幕距离、管径或长度来选择对应。

## 属性及验收

本规则只产生节点和区间对应，不赋管径或物理长度。随后复用既有平面管径、原生路径长度和元件归属模块；轴测竖直区间仍只取 11 图。未知内部长度不填零。正式入口验证为 `validate-anchored-cycle-gate-batch --cycle-run`。

原图只用于自动核验提取及对应证据，图片用于剩余冲突的人工判读。源证据通过、查看器发布和人工验收分别记录。

SH16 回归覆盖 08–10 全部普通节点锚点；09 二层供回水环入口是正例，内部支路数不一致是保留反例。测试包含镜像坐标、不同管径、单锚点、异系统、跨楼层、断口、重复入口签名和带弦／平行结构。

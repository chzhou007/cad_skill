# 环路新入口必须继承复合载线屏障

已有规则 `compound_carrier_members.carrier_risks` 是物理成员确认前的屏障，必须同样应用于环路入口、立管角色、直接区间及中心线属性入口。不能因为几何三臂、唯一拓扑路径或长度单位已通过，就跳过同投影多管成员识别。

执行顺序为：完整历史提供者回放 → 图示环路／立管候选 → 原生复合载线屏障 → 成员拓扑与端口 → 物理对应 → 属性。用 `reconstruct-cycle-carrier-guards`、`validate-cycle-carrier-guards`，随后 `validate-cycle-carrier-correction-viewer`、`reconstruct-guarded-cycle-provider-inventory` 及其验证。旧 `validate-typed-cycle-riser-batch` 的成功仅表示图示角色源证据通过，仍是 pending，不能作为物理成员确认。

屏障按原生 LINE、图路径原子及源声明追踪，复用原有读取器，不按距离临时豁免。声明候选不等于文字归属或成员归属。无关正交复合边臂若已有唯一直接管径证据，可继续使用既有 `compound_carrier_fragment_scope.qualify`；没有该证据时保持屏障。管径数值不同本身不代表新变径，也不能据轴测水平管径替代平面成员证明。

保留三层状态：图示路径及其投影长度、物理成员候选、已确认的物理对应及属性。屏障未消除时，图示长度有来源仍可展示，但不叫完整物理水平管长，不进入完成数，不让图示三通继续成为自动继承的物理锚点。源图、旧候选及旧批注完整保留；相关语义确认失效。

SH16 的本轮反例是 09／11 环路入口6段及其相邻立管角色。旧入口漏接载线屏障，导致图示投影被提升为完整水平管长。纠正只撤回指定6段的活动物理声明；其余历史字段、200条已齐全水平边、竖管分段和元件归属均须精确保持。原149阶段产物保留作历史，新查看器明确显示“图示投影，物理成员未确认”。新完整提供者清单将候选6段及其4个图示锚点隔离，不继续向后传播。

原图大范围与局部对照用于消化提取／成员归属问题，不能将已有专家确认的“两根叠管”含义重复提问。元件在两个视图中的分布差异及13／14末端数量差异应先在成员层复核，源图确定的问题修复后重算；真实原图冲突才进 HIL。

回归要求：源屏障整批读取、角色点所有相邻边（包括长弧之外的短边）、旧数据只读、指定活动值撤回、图示证据保留、旧竖管及成员命名空间守恒、失效屏障不可恢复旧物理声明、中文UI、真实CSV与完整提供者清单。技术纠正不等于 SH16 验收或 LF20 回测。

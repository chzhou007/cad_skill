# Connect independently qualified members through original inline corridors

Run `rebuild_compound_member_bridges.py` on the complete source-pinned member
interface artifact. Screen every external port, including unmatched boundaries;
do not manually select only easy positive edges. Pair reciprocal native Ts on
one axis LINE with two independent plan member boundaries. DN is never a
mapping key. Preserve the other external ports and the original local graphs.

Reuse original native inline-chain and calibrated flexible-joint readers. Clip
their ordered LINE/joint intervals at the actual member nodes, reject missing
coverage, partial joints, interior circles and unresolved DN annotations. A
nearby label outside the interval is not an in-scope change. Nested, unsupported
and mirrored annotations retain conservative scope barriers.

Rebuild the member edge before publishing its attributes. Inherit DN only when
the two independent plan members agree and the native through-T/axis label
checks agree. Match actual ordered valve/joint source instances and profiles;
equal counts are insufficient. Keep original edge/component identities and all
third ports. Measure only actual plan pipe projections: inline graphic extents
are not physical component length or complete centreline length.

Use `validate-compound-member-bridges` followed by the versioned
`validate-compound-bridge-attribute-refresh`. The refresh preserves the qualified
vertical-aware parent, every old vertical field and unrelated effective value.
Its old qualification is dependency checked; only the new geometry is freshly
replayed. Actual UI/CSV, source overview/local comparisons and inherited tests
must pass. Related HIL is invalidated while old annotations remain historical.

# 11图连续源管路的竖直段管径

原有单路径继承只搜索竖直段标注，可能漏用同一管路水平段的11图标注。三通与弯头组合也必须组合回证，不能只比较最终竖直段是否和种子共用 LINE。

使用 `reconstruct-axis-continuous-source-DN --manifest <固定输入> --output <新目录>`；用 `validate-axis-continuous-source-DN --dn-run <目录>` 独立重读原CAD。输入绑定当前已发布的竖向域及完整剩余清单。

1. 使用原有原生文字、段投影、源线竞争及 F 引线内核，重新读取所有方向的模型空间管径。发现器的排除参数是文字 ID；F 的源句柄须先转换为对应 ID。水平标注在本入口只作继承种子，不替代平面图最终水平属性。
2. 同一路径内使用原有两臂弯头连续性检查。其他路径可以经一条原始 LINE 的真实三通主管接入，再经过原有两臂弯头到达目标竖段。每个中间三通必须重新验证完整三臂，两个主管臂共用该源 LINE；支路自身的管径不反向作为主管种子。
3. 原生同系统端点接入主管但图中没有可回证 T 时保持待处理。普通内部交叉不由本规则补成连接。重复源线、额外支路、断口、源覆盖不足或系统冲突均阻断。
4. 通用距离屏障可能扫到另一根管道的文字。只有原有归属读取器已重新证明该文字属于另一系统或不重叠源线，才排除该文字。同一源管路的不同管径、未归属文字、复合管径及 F 引线继续阻断；同管径的已证明原标注可共同保留为继承依据。
5. 只输出原始竖直段 ID、源线、种子、三通／弯头和标注屏障证据。物理长度、整边管径和水平最终属性不在此入口赋值。查看器采用和人工验收另行记录。

回归 `test_axis_continuous_source_vertical_DN.py`：水平标注→真实 T 主管→弯头→竖段；支路小管径不反向覆盖主管；下游新标注覆盖上游继承；复合标注、供回水混接、重复源线、漏建 T 和仅有支路种子均受保护。原有单路径和省略符继承测试同时运行。

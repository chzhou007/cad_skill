# 当前取值、导出主字段与缺项清单一致性

源级管径已被完整成员证明且页面已显示时，导出主字段也必须反映该值。复用 `checkedRiserHeaderMember` 的全部原校核，仅对 `approach` 且完整水平中心线成立的成员补此前未知的主字段；`riser` 成员的局部已绘管径不提升为整边值。保留全部已有非空管径、长度、竖段、元件、共享量测和来源列。

`refresh-effective-provider-viewer --parent OLD --output NEW --intervals NATIVE --templates T --port PORT` 重新验证完整父查看器及原完整成员入口，随后从**实际应用使用的属性读取器**生成当前缺项清单。用 `validate-effective-provider-viewer --verify-output NEW` 独立复验。294列保持原顺序，只允许完整水平成员两条既有DN300的主字段采用，不增加物理属性推断。

缺项清单的每行 `attributes` 来自当前有效取值，不能复制旧快照继续声称缺管径。已证明同范围统一DN、尚未分摊逐边长度的行，进入范围内量长任务，仍不赋内部节点身份，不增加普通节点映射。来源观察、成员命名空间、所有竖段和元件清单保持。

整边主字段计数、局部DN范围数、水平DN与完整中心线同时成立数分别统计。圆圈或立管符号内部未画接管长度仍未知；完整平面中心线不是安装或净下料长度。共享64.700米不能按边重复累计或分摊。

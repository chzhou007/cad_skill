# 平面主管管径经真实三通继承的查看器接入

先完成 `reconstruct-plan-seeded-axis-branch-DN` 的原生资格检查和独立重放。然后使用 `refresh-plan-seeded-branch-DN-viewer`，保持当前完整属性入口、元件覆盖、全部旧上下文、来源坐标和批注目录。

- 水平管径只来自重新回证的平面主管及轴测真实三通／完整支路证据。不同数量的设备表达不自动产生逐台设备对应。
- 若要填整边 DN，必须按边、路径、区段、源点列、系统和11图原始来源逐项核对现有竖段证据，证明除绘图标记圆心显示段外的每个物理区段均被覆盖且 DN 一致。不能仅靠两个值相同或记录数量相同就填整边。
- 竖段记录逐字保留，未覆盖或冲突时只能显示水平区段 DN。已有整边值不覆盖；任何长度、原映射和元件记录均保持原值。未知长度不填零，接口显示短线不计物理长度。
- 输出六个独立 CSV 证据字段，更新有效整边 DN 统计；个体跨图对应的缺项不因标量管径已知而消失。相关人工确认不自动继承。

`validate-plan-seeded-branch-DN-viewer --verify-output ...` 须重跑原生 owner 并核对实际完整属性入口、数据版本和每个差异；实际浏览器中文、两系统全网导出及元件守恒另验。技术通过不代替 HIL。

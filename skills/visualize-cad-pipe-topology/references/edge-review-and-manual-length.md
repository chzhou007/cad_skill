# Edge review labels and direct length editing

Use the current, source-bound attribute frontier to mark edges, with a reason for each label. A missing attribute is not proof of a connection defect or a new expert question. Do not regenerate answered interpretation questions, use raw LINE coverage alone, or mark all unaccepted edges as faults. Mixed paths still need separate correspondence and length status. Filter labels and the list by current floor/system; selecting either must focus and highlight the exact edge, using ordinary segment selection rather than network scope.

`enable_edge_review.py --parent VIEWER --output NEW_VIEWER --provider CURRENT_PROVIDER --port PORT` adds the shared UI without changing graph/source/component bytes or the old attribute reader. Generic builders copy the same assets and initialize the editor; an optional `data/edge-review-queue.json` supplies dataset-bound labels.

The right inspector accepts a finite positive **whole-edge physical length in metres**. It is a directly effective manual authority, not a change proposal. `PUT /api/edge-review` uses the existing same-origin JSON boundary, exact dataset and review revision. Values, reset operations and per-edge review status are persisted atomically in the existing `annotations/<datasetId>/review.json` plus revision history. Keep `edgeEdits`, `edgeEditHistory`, historical comments and confirmations in backups/packages. Changing a length clears that edge's reviewed status and invalidates global acceptance; archive the prior confirmation. A manual length does not prove equipment identity, supply/return connectivity, a CAD dimension or subsegment allocation.

Display the manual value prominently and retain all original source properties below. Reset removes only the current manual authority; source values and past edits survive. An explicit per-edge reviewed action clears its pending label but does not fill missing source data or attest the entire graph. Invalid and stale edits must fail visibly without overwriting another window. Synchronize the existing HIL revision after an edit; retain unsaved notes on conflict.

CSV retains all old source columns unchanged and appends review status, reason, manual length, effective length in metres and authority/author/time. A complete, source-qualified whole-edge value may be used as the default effective length; partial plan XY, group totals, drawing units, axis horizontal annotations and unknown lengths must never silently become whole physical lengths. Component CSV stays unchanged. This layer does not change the old drawing-unit path calculator.

Run `test_edge_review.py`, `test_edge_review.mjs`, existing HIL/frontend and relevant builder tests. Verify actual clickable labels, focus/highlight, save, reload, reset, Chinese, whole-network CSV and original-cell/component conservation in a real browser. Use an isolated QA viewer for demonstration edits; never leave invented test lengths or QA acceptances in the delivered dataset.


## Diameter editing and persistent notes

`upgrade_edge_attribute_editor.py` upgrades a published directional viewer in a fresh directory, preserving source data and all annotations. Experts may edit DN in millimetres for `horizontal`, `vertical` or an explicitly uniform `whole_edge`. Store values under `edgeEdits[id].diameters[scope]`; direction-specific overrides take precedence over a whole-edge manual DN. Preserve original values and segment evidence; a manual diameter does not prove connectivity, an individual mapping or engineering suitability. Reset only the selected scope. Invalidate prior edge/global review on changed attributes.

Notes are independent state (`edgeEdits[id].note`), not disposable input attached only to length saving. A dedicated `saveNote` action works without a length or DN. Refill after save, rerender, edge navigation and reload. Recover old invisible notes from the stored length/review and per-edge history, but honor an explicit new empty note as a clear. Retain dirty per-edge drafts through render and failed/stale requests; saving another field must not discard unsaved input. Keep actual error text visible.

CSV keeps the prior prefix and appends six diameter/remark fields; JSON and the directional inspector apply the same manual scope precedence. Preserve raw CAD diameter fields. HIL backup includes all edits, notes and history. Verify both scoped and whole-edge DN, reset isolation, old-note recovery, multiline Chinese, note-only saves, reload and actual CSV/JSON exports on an isolated extracted package. Use `test_edge_attribute_review.py` and `.mjs` in addition to existing edge-review, directional and HIL tests. Distribute a fresh complete ZIP and preserve expert annotation folders when replacing older packages.

## Full backup restoration and offline instance ownership

Import JSON must roundtrip the full review document, including manual length, all three DN scopes, Chinese notes, explicit clears, issue revisions, expert replies and histories. Use the same-origin revision-checked `POST /api/restore-backup`; validate the complete payload before any write, reject foreign datasets/unknown active edges/invalid attributes, archive the replaced state, and invalidate whole-dataset confirmation. A legacy backup without edits explicitly restores no manual overrides. This is a replacement, not an automatic merge of conflicting offline copies. The confirmation dialog must state the full replacement scope. Refresh both the editor and effective directional inspector after restoration. Run `test_offline_review_roundtrip.py` and verify export/import/reload through the actual extracted UI.

Only reuse a running service when `/api/instance` matches both bundle and normalized extraction-directory identity. An identical ZIP extracted elsewhere owns a different annotation store and must select a free loopback port. A fixed-port request may fail rather than silently use another folder. Keep the actual URL visible in the launch log, same-origin mutation protection, local bind and payload verification intact. `upgrade_offline_review_safety.py` upgrades an existing result in a fresh folder without rewriting CAD values or annotations.

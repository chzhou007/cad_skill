# 连续轴测源管路的竖直管径发布

原生 `continuous-source-vertical-DN.json` 独立回算通过后，运行 `refresh-continuous-axis-DN-viewer`，提供固定父查看器、证明、模板、新输出及端口；随后用 `validate-continuous-axis-DN-viewer --bundle <目录>` 独立重读新增源证明并核对完整有效属性。

新上下文 `continuous_axis_vertical_DN` 保存原边／路径／段、种子标注句柄、原生三通及弯头规则、源文件与图版本。水平标注只提供11图原生继承证据；水平最终值继续来自平面图。整边管径与物理长度保持原状态。

新查看器入口继承完整父属性读取器，然后追加连续源竖向域；不能用早期的基础读取器替换后续父入口。CSV 末尾增加三列 `axis_continuous_vertical_DN_*`，父文件的所有列顺序、所有单元格值保留。包含多个新增段的同一边，按段逐项导出，不合并为整边管径。

实际验收需检查不同楼层和两系统的中文属性、原标注与三通链，以及两套完整同系统网络导出的全部边。技术源回证、实际属性采用和人工验收分别记录。父产物继承不冒充重新执行全部历史父阶段。

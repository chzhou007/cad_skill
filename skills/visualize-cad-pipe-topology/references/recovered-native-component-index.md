# Adopt recovered native components into the rendered index

Use after the topology owner's [known-family native recovery](../../build-cad-pipe-topology/references/native-risk-origins-and-balancing-reapplication.md).
Recognition, source inventory, rendered index and cross-view profile acceptance
are separate deliverables. A source-only recovery is not a finished viewer fix.

Run `reconstruct-recovered-component-index` and
`validate-recovered-component-index`. Pin the complete current provider and
parent viewer, recovered inventory, native axis graph/DXF, current ordinary
plan graph/CSV, member allocation proof/CSV and explicit source display type.
The owner independently replays the complete provider and native inventory.
Reapply the existing component-profile and legacy-inventory readers to affected
mapped scopes. Ordinary and reconstructed-member allocations stay separate.
Bind ordinary profiles by the source graph's unique floor and the complete
provider's corresponding `plan_graph_<floor>` identity. `ordinary_plans` can
name several pinned graph/CSV input pairs. Same edge IDs on different floors
are separate namespaces. Missing floors, conflicting observation floors and
mixed ordinary extents require their original scoped profile owner.
An unmatched edge remains unmatched; component counts cannot establish mapping.
Profile conflicts or unsupported grouped allocations stop publication and return
to their owning correspondence rule. Never silently inherit the old acceptance.

Reuse the original builder's numeric positions, symbol loader, native source
attributes and instance geometry. A recovered anchor may be far from the raw
INSERT origin; use its proven top handle and transformed WCS ports, not a new
nearest-origin search. Preserve every old instance ID/payload, node, connection,
source path and attribute. New IDs derive from actual source handles. Combine
several recovered instances on one edge without losing their individual IDs.
Update per-edge inventory, type/symbol declarations and viewer counts together.
Native ownership failures stay in the source inventory and remain visible in
the delivery status. Missing physical parameters remain unknown.

Publish with `refresh_recovered_component_index.refresh` and
`validate-recovered-component-viewer`. The new graph is a versioned render
derivative. Its native proof must restore the exact previous JSON graph after
removing only the declared index/type/inventory additions. Keep the historical
attribute context and original source proof hashes intact; do not rewrite those
proofs to claim a new graph hash. Add an explicit component-inventory attribute
bridge that binds the actual new graph hash to that original attribute domain
and checks unchanged edge identity, service, floors and paths. The browser fails
closed outside the proven scope. Every effective pipe CSV value must remain
exact. Base CSV component counts change only on the declared affected edges.
The dataset loader must also verify the actual new whole-file SHA256 through
this explicit bridge. Native schema success alone does not prove that the
browser can load a changed rendered graph; keep the original hash rejection
for every unbridged or altered graph.

Run the full native source geometry/schema gates and verify actual component
inspection, source highlighting, network totals, instance/edge CSV and Chinese
pipe properties. Semantic component changes produce a new HIL bundle identity;
old annotations survive as history and confirmations are not inherited.

Finally run `reconstruct-recovered-component-provider-inventory` and its
validator. Retain every ordinary/member provider, junction map, pipe attribute
and pending frontier. Point subsequent batches to this current inventory and
native component list. Adding recovered components does not create extra pipe
correspondences or DN/length values. Preserve unresolved source components.

SH16 control: 1564 prior instances plus 9 independently recovered balancing
valves; six ordinary profiles and one member allocation agree, two affected
edges remain unpaired. A tenth native symbol lacks unique pipe ownership and
is not force-assigned. These counts are fixture evidence, not global thresholds.

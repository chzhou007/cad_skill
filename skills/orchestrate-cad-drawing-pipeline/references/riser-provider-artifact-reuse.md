# Reapply the complete riser provider artifact

Use `reuse-riser-provider-artifact` for repeated checks of an unchanged complete
`riser_header_provider_inventory` output. This fixed-owner adapter reuses the
existing `reuse_attribute_native_artifact` import setup/observed Node reader and
the unchanged `reuse_verified_native_artifact` capsule/closure engine. Original
cache and verifier modules are not edited. A complete immutable parent skills
root avoids invalidating that parent solely because a later child adds code.

Default to the existing v2 native owner batch so already imported verifier
aliases receive its original current-content checks too. An explicit runtime
version remains respected. Record unsupported open-event metadata for diagnosis;
it must never turn an uncacheable run into a cache hit.

Supply `--skills-root`, `--native-run`, `--cache-root`, and a fresh `--output`.
Cold runs execute the original complete native owner. Warm runs must freshly
check the complete runtime/skill bytes, original proof bytes and every observed
transitive file/directory/negative-probe dependency. Keep import dependencies in
the capture; initialize the existing numerical runtime and import-time path
changes before the original before/after binding. Unknown side effects remain
uncacheable. Never remove an input from the fingerprint to obtain a cache hit.

Report `native_replay_performed` and `dependency_checked_reuse` distinctly, with
measured wall time and cache storage status. A passed original native read whose
environment binding changes is not a reusable capsule. The original full-native
validator remains available as an independent control. Reuse never creates new
correspondence, DN, lengths, component ownership or human acceptance.

The fixed isolated worker uses its shipped environment policy for transport-only
context metadata, restoring the caller on exit. The complete before/after
environment and policy bytes remain bound. Only the unchanged bounded-parent
child can use the observed bridge: require its complete capsule, proof, current
dependency closure and original checks before merging its observed reads. The
native vertical-DN executor runs the original worker functions in a private
observed namespace so source opens remain visible. Original group partitioning,
sort order, qualifications and proof bytes must match. Unknown subprocesses
still disable reuse. Do not apply these exceptions to arbitrary process I/O.

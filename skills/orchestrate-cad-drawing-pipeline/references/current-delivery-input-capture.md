# 当前交付的实测输入清单

分发Skill和一个能打开的查看器，不等于固定输入能完整重建。先运行 `capture-current-delivery-inputs --skills-root IMMUTABLE --viewer CURRENT --output NEW`：它调用当前真实查看器的完整原生验证，复用原有文件、目录和负探针观察器，并在执行前后绑定完整Skill及Python运行库字节。

捕获结果保留实际读取的文件及哈希、原本不存在的文件、目录和探针状态，以及尚未封闭的子进程边界。未追踪的Node读取或隔离原生父进程不能靠忽略审计事件使结果变绿。已观测文件字节一致，只能证明这些输入仍相同；不能自动证明所有进程输入均已覆盖，也不能把它写成完整固定输入分发通过。

导入期间搜索路径可能变化。保留执行前后两份完整绑定与差异；只变化搜索路径也不构成可复用绑定的证明。代码、运行库、环境或已观测输入改变时，保留诊断后失败，不能把改变后的哈希覆盖到原绑定。

Windows进程审计可能传入完整命令字符串，且未单列可执行文件。按系统 `CommandLineToArgvW` 解码后分类，保留原始参数指纹；不能把字符串当成只有一个参数的列表。命令指纹识别只证明调用类型，不封闭该进程实际读取的输入。

后续封装应复用已有只读Node输入桥和原生父产物的完整依赖胶囊，分别验证实际前端读取器、所有相对模块、引擎与包配置，以及子进程的源图、策略和运行环境。负探针和目录约束继续保留。完整闭包、离线取出后的重放与实际查看器／CSV应分别验收；源图歧义和人工验收状态不因打包而改变。

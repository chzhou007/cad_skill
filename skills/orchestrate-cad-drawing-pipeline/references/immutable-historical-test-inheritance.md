# 历史原生入口的测试资产继承

完整历史入口可能锁定生产脚本和测试脚本的字节。新增反例追加到已锁定测试文件，虽不改变算法，也会使严格父入口失效。不能把测试文件排除在旧校验之外，不能改旧哈希或把局部通过当成完整入口通过。

若差异仅为新增测试方法，先逐行证明旧方法、fixture及算法未改动。将新增案例移至独立测试模块，保留全部断言及具体源证据，恢复历史测试文件的精确原始字节。新测试须登记并纳入全量执行，不得以恢复旧文件为由丢弃新反例。

`audit-bounded-parent-inheritance --manifest M --current-root SKILLS --output NEW.json` 检查不可变原树和所有原有生产／测试字节，调用未改动的严格校核器。该输出只证明资产前置检查；随后必须执行原完整原生入口及其独立验证，并逐项核对旧输出、源图、元件和属性。任何真实算法或原测试行为的差异仍需重新构建父产物。

SH16 T306 的 DIM_SYMB 折线不能替代未画的管道覆盖，新增断言已移入 `test_omission_marker_native_T_gap_guard.py`。历史三射线测试恢复原字节；T306 的2.35484绘图单位缺口仍保持未证明。该资产整理不解决其物理连接判断，也不赋长度。

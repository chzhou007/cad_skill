# Fresh parent producer receipts are inputs with a distinct role

Use when a source-generated graph/component pair passes its original generated-local-parent proof, but the producer observer treats reading that same proof document as an unproved owned output. Do not convert the proof into a startup seed or allow arbitrary work-directory reads.

`producer_parent_receipt_observation.py` inherits the exact hash-bound original observer. The producer binding adds `base_observer={relative,sha256}`. Only exact `producer_receipt_relative` identities referenced by `generated_local_parents` receive the new read-only role. Recheck the receipt hash, original producer mode, actual graph/components pointer, exact output comparison flag, each output hash and work containment. Keep native return bytes/stat and every original observer/native-copy/process rule. Writes, reference_graph roles, escaped paths, modified proofs/outputs and unrelated work files remain rejected. This role establishes input provenance; it does not certify CAD correctness or general native I/O closure.

`pipeline.py build-parent-receipt-producer-policy --producer-result RESULT --package PACKAGE --seed-manifest SEEDS --output NEW` replays the original policy owner on a private typed view. A previously unresolved owned read can be reclassified only when the exact fresh-parent receipt and all outputs independently pass the same proof. Preserve original report files, hashes, events and strict-failure state. The new derivation records each reclassification and separate receipt bindings. Remove these receipts only from the fixed-package/seed domain; keep all other original ownership, state, negative probe, process and input guards. `--verify-output NEW` independently derives again. Neither derivation nor the 8-parent preflight proves full producer execution; run the actual production process tree afterward.

Cover actual bytes/stat, read-only identity, receipt/output mutation, original observer mutation, reference/escape/bool-pointer rejection, original held case, private reclassification and unrelated owned-read protection. A complete native production run and current review delivery remain separate evidence.
